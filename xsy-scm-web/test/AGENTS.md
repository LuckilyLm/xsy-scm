# 后台本地回归

- 已退役SQL只通过helpers/source-reader.mjs从清单指定的Git对象读取；当前资源优先直接读取，不恢复旧迁移目录。浏览器配置改名须覆盖旧值迁移、新值优先与存储写入失败保留原值。

- 源码约定检查保持金额字段、权限、版本、校验分支与提交结构断言，界面文案以当前页面和 `docs/decisions.md` 为准。
- 页面文案或正式规则变更后，同步更新相关断言，不恢复已废弃的交互以满足历史测试。例如首页空组件允许发布配色，但保存、发布权限和版本控制仍必须验证。
- 纯逻辑测试验证实际返回和边界；真实接口、下载文件与页面交互由 `e2e/` 和 `e2e-chains/` 验证，不能以源码字符串检查代替业务链验收。
- 完整数组报表使用LocalTable后，页面回归应逐页核对业务行与接口全量结果；不能要求所有行同时在第一页出现，也不能只降低到第一页数量而丢失跨页校验。
