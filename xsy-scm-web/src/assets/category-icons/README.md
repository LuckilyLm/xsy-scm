# 商品分类可选图标

用户交付原图，用于后台选择分类图标。来源路径、原始哈希及当前字节哈希见sources.json；默认保持原色和透明边缘，不着色或另行绘制。

选择后复用正式文件上传接口，分类只保存公开文件标识，小程序通过MinIO在线加载，不把本目录编入小程序代码包。国产水果为苹果梨图，进口水果为葡萄图；两图不同，不能为素材去重把两个业务分类映射成同一幅图。鱼类只保留鱼虾图。

tools/configure_category_icons.py是显式资料配置入口：默认只输出计划，传入apply才发布图片、注册文件并补齐缺少空分类；保留已有人工图标及商品归属。存储依赖沿用小程序tools/requirements-media.txt，凭据仅通过环境传递。执行前完成V1005迁移，之后的分类编辑可直接在后台进行。
