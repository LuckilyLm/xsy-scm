# 订单页面

- 页面交互规范遵循根目录 `DESIGN.md`；接口类型在 `order-types.ts`，表单转换在 `order-form-model.ts`。
- 明细输入新增或调整字段时，同时检查 `payload()` 与 `test/order.test.mjs`；整单备注与商品行备注分别提交，空行备注应可显式清除。
- 商品选择只修改当前行数据，服务端负责判定替换商品后的身份与分拣/出库限制，不能依赖页面禁用控件保护历史事实。
- 正式订单详情页展示服务端整单remark，客户的小程序下单要求不能只保存在接口里而在后台遗漏；与商品行备注分开展示，复用详情字段布局。
- 客户订货/送货Excel从订单详情调用专用出口，按钮沿用报表导出权限和统一下载错误处理；前端不根据采购参考价重算客户销售额。
