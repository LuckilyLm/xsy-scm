# 商城装修后台

- 页面按首页、弹窗、单页和店铺分区，各自保存/发布；权限和版本仍由正式接口裁定。
- `mall-phone-preview.vue` 使用 `utils/mall-theme.ts` 派生渐变，分类与快捷入口采用 `assets/mall-visual/` 的交付PNG；领券归入“我的”，首页预览不加固定领券横条。更改预览同时检查小程序对应实现，主图和专题保持2.5:1/3:1完整比例，图片有文案时不重复叠标题。
- 首页组件为空仍可发布配色，预览说明默认首页保留；不可把空布局视作发布失败。
- 首页与我的共用顶部渐变，支持分别设置主色和起始/结束色，默认浅绿白；四季与常用节日预设集中在utils/mall-theme.ts，选择后同时更新全局主色与实际端点。输入、预设和恢复默认都需标记未保存，保存期间新增编辑不得误清dirty。
- 顶部渐变随首页发布和回滚，手机预览与小程序使用相同端点和前景对比规则；预设后续改名或改色不得影响既有发布记录。
- 店铺设置成功后通知父页面更新名称，二维码始终基于已保存链接。
- 预览的分类/快捷素材只复用 `assets/mall-visual/` 中的用户交付图片，不另建SVG素材集；清理不用的素材时核对源码引用与小程序对应副本。
- 手机预览的六类示意入口允许横滑，不能裁掉后三类；正式小程序仍以后台启用分类树为准，空分类保留入口。
