# 本地待同步凭条尝试

2026-10-16，执行者 Codex。仅秤端SQLite增量，不连接或修改集团PostgreSQL；首次打开旧数据目录自动建立表和索引，无破坏性迁移。

```sql
CREATE TABLE IF NOT EXISTS local_tickets (
  attempt_id TEXT PRIMARY KEY,
  operation_id TEXT NOT NULL UNIQUE,
  request_hash TEXT NOT NULL,
  event_key TEXT NOT NULL,
  scope_key TEXT NOT NULL,
  payload TEXT NOT NULL,
  state TEXT NOT NULL,
  spooler_job_id TEXT,
  error_code TEXT
);
CREATE INDEX IF NOT EXISTS ix_local_ticket_scope ON local_tickets(scope_key);
CREATE INDEX IF NOT EXISTS ix_local_ticket_queue ON local_tickets(state);

-- 恢复执行中断的打印。保留原事实，不将未决尝试重新入队。
UPDATE basket_records SET print_state='UNKNOWN' WHERE event_key IN
  (SELECT event_key FROM local_tickets WHERE state='SUBMITTING');
UPDATE local_tickets SET state='UNKNOWN', error_code='AGENT_RESTARTED'
  WHERE state='SUBMITTING';
```

`attempt_id`为本地执行编号，首次使用本筐printIntentId，补打追加新编号；不是平台printAttemptId。`operation_id`与采集/完成共享逻辑命名空间；同请求重复不追加。`payload`冻结原筐凭条、纸张和打印队列；每次补打只追加，不改重量/时间。`state`列为当前执行状态，读取时覆盖payload初始值。

筐记录、CAPTURE_BASKET命令及首次本地凭条在同一事务写入。先将QUEUED改为SUBMITTING再调用驱动；执行中断或无法确定出纸均UNKNOWN，不自动重打。驱动明确拒绝为FAILED；Windows接受为SUBMITTED_TO_SPOOLER；隔离演练为TEST_ONLY。

既有settings表增加`workstation_mode`（LOCAL_TEST/FIELD）与DPAPI加密的`workstation_operator`引用；无额外DDL。演练不能使用已存事实的未标记库，也不能与FIELD库互换。不开启本地凭条时，旧筐print_state继续WAITING_AUTHORIZATION。
