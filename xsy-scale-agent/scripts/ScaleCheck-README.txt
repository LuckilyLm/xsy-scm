鲜蔬园 · 实秤读数检查包（2026-10-20）

这不是完整安装包。它使用你已经复制到秤上 Win10 的鲜蔬园 0.3.0 程序。

1. 在秤的 Win10 上，关闭串口调试助手，释放 COM1。
   仅点击“停止显示”不够，需关闭串口或退出助手。

2. 将本压缩包的全部五个文件解压/复制到 Xsy.Scale.Agent.exe 所在文件夹。
   不用修改 appsettings.Local.json，不用重新复制原来的大程序包。

3. 双击 Start-ScaleCheck.cmd。保持检查窗口打开。
   依次观察：空秤 → 放一件物品、等待稳定 → 拿走物品。
   默认检查 60 秒，也可按 Q 提前结束，请不要直接点击窗口右上角关闭。

4. 看窗口是否显示重量变化、稳定性和毛重/净重。
   例如 sg0000.68sj 应显示原始 0.68 市斤、换算 0.34 公斤、毛重、稳定。
   收到数据只证明程序能读重量，不代表已校准，也不代表已经完成分拣上传。

5. 结束后，程序文件夹会出现 hardware-check 文件夹。
   将其中最新时间开头的整个结果子文件夹带回办公电脑发给 Codex，或先拍检查窗口。
   结果包含 result.json、readings.jsonl、启动日志和本次进程信息，不包含访问密钥。

如果窗口一直没有读数：
- 先确认串口助手和其他占用 COM1 的程序已退出。
- 如果上次检查意外关窗，双击 Stop-ScaleCheck.cmd，再重新启动检查。
- 不要自行改变串口协议、波特率或打开去皮/置零。保留结果文件供分析。

本检查只使用 COM1、9600、8N1、无流控的连续 RS232 读数。
它使用独立数据目录，不复用正式任务/凭证，不发送去皮置零，不保存业务筐，不打印。
Start-LocalTest.cmd 是模拟演练入口，本次真实秤测试请使用 Start-ScaleCheck.cmd。

维护说明：检查状态放在当前 Windows 用户的
%LOCALAPPDATA%\XSY\ScaleAgent-HardwareCheck\每次独立目录。
结果保存在本程序旁 hardware-check。保留这两处文件，不需要删除或安装自启动。

执行者：Codex。检查包面向已交付的 Agent 0.3.0 win-x64。
