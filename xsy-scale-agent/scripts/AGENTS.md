# 秤端脚本约束

- PowerShell 脚本保持 Windows PowerShell 5.1 可用，使用 UTF-8 BOM；批处理启动器使用 ASCII。启动与停止脚本只能操作已核对 PID、启动时刻和可执行路径的自有进程。
- 本地演练、硬件测试和正式运行使用独立状态目录。普通演练不得访问现场串口或真实打印队列；硬件测试必须由操作者显式开启，不自动清理旧筐、票据或数据库。
- `Start-ScaleCheck.ps1` 只读取现有设备状态，不发送去皮、置零或标定命令，也不写个人配置。未知端口或驱动错误只报告，不通过改阈值掩盖。
- `Export-HardwareTest.ps1` 只导出受限测试任务的记录与状态，不复制 API 密钥、员工授权、数据库或个人配置。导出失败保留现场与错误信息，不为了形成完整报告删除原始记录。
- 真实设备的去皮、置零和打印须由现场操作者明确触发；`SUBMITTED_TO_SPOOLER` 不代表已经出纸。工具不得自动重发不确定的控制或打印命令。
- 发布时保留本机数据目录与未同步命令。正式配置与凭据不得进入发布包；测试包必须明确标记测试身份及隔离输出。
- 脚本的执行与验证遵循仓库根目录 `AGENTS.md` 的授权要求。历史现场记录不能替代当前版本的实机验收。
