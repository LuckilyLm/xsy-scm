# 秤端脚本约定

本目录负责构建/发布、模式隔离、启动/停止、只读设备检查与结果导出。共用业务约束见上级 `AGENTS.md`；不在脚本中另建计量或平台规则。

- PowerShell 文件使用 UTF-8 BOM，兼容 Windows PowerShell 5.1；CMD 启动器使用 ASCII。不要把现代 PowerShell 独有语法带到现场包。
- FIELD、普通演练和硬件联动保持独立数据目录与端口。普通演练不读真实串口、不调用真实打印队列；硬件联动必须显式启用、测试设备码、回环测试平台与指定打印机/60×40 纸型，禁止回退默认打印机。
- 新市斤演练/硬件默认目录保留 `0.4.0` 后缀；不自动搬库或重标旧公斤记录。升级先停旧包并导出，新包完整解压到独立目录。
- 停止进程前同时核对 PID、启动时刻、完整路径，仅回收本脚本启动的实例。端口被占用时说明冲突，不结束无关进程；不清打印队列、不重置业务库。
- `Publish-Agent.ps1` 随包复制 `FIRST-GENERATION-HANDOFF.md`、接口/SQLite 说明和必要第三方许可；调整文档路径必须同步修改复制清单。保留旧构建与安装包，不覆盖原包。
- `Collect-ScaleRaw.ps1` 在服务已停后只读采集，不发 T/Z/AD 等指令、不写业务或打印。原始分块与解析状态分开；未知单位不猜测为业务事实。
- `Start-ScaleCheck.ps1` 及 Stop 脚本只读诊断，使用独立状态与进程身份，health/status 定时抽样不等于逐帧串口抓包；收到数据不代表计量或完整作业验收。
- `Test-Label60x40.ps1` 默认生成预览，只有显式 `-Print` 才提交指定队列一次、一页、一份。测试标签明确非业务，不读秤、不写库；驱动受理不记物理成功，UNKNOWN 不自动重发。
- 硬件联动导出经只读 API 收集状态、记录、累计、命令和票，不复制密钥/凭据/数据库。PS5.1 数组保留原始 HTTP 内容，避免 Count/value 包装漂移；导出失败保留错误与现场。
- 软件去皮/置零只有显式授权时启用；打印预检警告不阻止仅上传，也不清理旧任务。设备连续输出与新鲜 NET 由真实读数证明，不延长旧采样有效期掩盖故障。
- 默认不运行验证或真实硬件。授权本机验证使用隔离替身/不存在端口，不盲开办公 COM1 或发纸；工具结果、平台回执与实际出纸分开报告。
