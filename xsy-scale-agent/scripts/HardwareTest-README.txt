鲜蔬园 0.3.6 实机联动测试（60×40毫米标签）

这是独立测试任务，读取真实电子秤，点击保存会真的打印标签。
标签明确标注“设备联动测试·非业务记录”，不连接正式平台。

1. 先在旧版目录双击Stop-HardwareTest.cmd导出并停止，再将整个0.3.6包解压到新文件夹，不覆盖旧版。
2. 关闭串口调试助手和之前的读重检查，释放COM1；开启X7并装60×40标签。
3. 双击Start-HardwareTest.cmd，进入按商品分拣选择商品，或按客户分拣选择客户；在任务列表点击“领取并称重”。
   首页仅两个分拣入口；商品选择、客户选择、可称重商品列表和称重页均可点“返回上级”，刷新后也能返回。
   进入称重后在左侧选择尚未完成的商品。
   若测试生菜已在旧版完成，可选择演练上海青或演练西红柿，不重新记录已完成商品。
4. 将筐与物品全部拿走，等重量稳定，点击网页“置零”，等提示“已收到设备稳定零读数”。
   再放空筐，等稳定，点击网页“去皮”，等同样提示并核对秤的净重零值，再放物品。
   每次只点一次；若5秒后显示“结果未确认”，先保持空秤/空筐并核对设备，勿立即加货或反复点击。
   软件没有伪造零值或自动重发。若设备不响应，可用实体键核对；仍不恢复时先Stop导出日志。
   本版取消50克倍数限制：稳定净重在1至150公斤范围内，8.55、8.84、8.86等均可按原读数记录。
   页面、每筐记录和标签保持同一原始净重，不四舍五入或凑成50克倍数。
   秤和商品均使用KG。本版未新增单位换算；10kg只是测试任务计划量，不是记录门槛。
   本版软件按钮已启用，不受1kg商品下限限制；但控制前必须重量稳定、连接正常且员工任务授权有效。
   串口不提供独立皮重时页面仍显示未知，不能以此判断去皮失败。实体按键仍可使用。
5. 点击“记录本筐并打印”，核对实纸商品、净重、筐号和记录号。
   若未出纸，先看“称重记录”的打印状态，不反复点称重或补打。
6. 取走商品、保留筐，确认净重回零；换另一份物品，点击“已换筐，继续称重”。
   稳定后再次“记录本筐并打印”，核对两条记录和累计，两张标签筐号不同。
7. 点击“完成商品”，按实际累计选择正常/短少/超出，按提示填原因。
   完成只冻结已有两筐，不另打印汇总标签。
8. 双击Stop-HardwareTest.cmd，导出结果并停止本测试的进程。
9. 将程序旁hardware-workflow内本轮文件夹压缩带回，并拍两张标签及累计结果。

记录保留在当前用户LocalAppData/XSY/ScaleAgent-HardwareWorkflow。
该目录不能与正式工作台或普通演练共用；重开不会清空筐记录。
重启后若提示授权/领取，重新领取原测试作业后查看历史，勿重复记录旧筐。
“已交打印队列”不保证实纸成功；结果未知时先核对再决定补打。
本版保留0.3.2的完整记录号标签修复；已保存但未出纸的旧筐，先查看打印状态并核对实纸。
确认失败且未出纸后，在“称重记录”对原筐补打，不重复新增重量记录。
普通Start-LocalTest.cmd仍只模拟重量和打印，不出纸。

0.3.5的T/Z软件命令仅完成本地模拟验证，须在本台Win10/电子秤确认实际响应。
Stop导出的status.json包含control及最近20次controlHistory，请在本轮操作后、重启前导出。
历史只在本进程内保留；重启不改变已存筐与票，也不能作为软件命令已成功的证据。

0.3.5新增入口：任务首页 → 按商品分拣 → 选择商品 → 领取并称重；也可按客户分拣 → 选择客户 → 进入同一商品称重。记录、累计和完成状态共用。
新标签右侧预留溯源查询区，当前平台网址未定，显示“查询入口待配置”，没有假二维码。旧记录补打沿用旧版式；可选择未完成商品测试新标签。软件去皮/置零及新版标签仍需在秤Win10核验，本地自动验证不代替实机结果。
