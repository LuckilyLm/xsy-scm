鲜蔬园 X7 60×40毫米间隙标签打印测试（2026-10-20）

在秤的Win10上使用：
1. 将这三个文件解压到此前的“鲜蔬园称重”程序文件夹。
2. 确认X7打印机已装好60×40毫米间隙标签纸并开机。
3. 双击 Print-TestLabel60x40.cmd，一次仅请求打印一张测试标签。
4. 看实际纸张：中文与重量是否清楚、四边框是否完整、是否只输出一张并停在标签间隙。
5. 拍下实际打印出的标签，并把程序旁 printer-check 中本次结果文件夹发回。

测试纸会明确印“打印测试”“示例净重”“非业务记录”，上面的1.250kg是固定测试内容。
这一步不读取秤、不创建分拣记录，也不连接后台。

若没有出纸或提示结果未知，请先拍窗口并查看队列，把本次结果带回分析。
脚本不自动重复打印，不清空现有任务，不修改Windows默认打印机或全局驱动设置。
Windows接受打印只说明提交了队列，实际出纸请以纸张为准。

每次结果包含 preview.png、result.json；能读取有效打印机时还会有 printer.json。
本脚本兼容Windows PowerShell 5.1，无需安装.NET SDK或新的驱动。
打印队列名固定使用现场已枚举的X7，找不到时会停止，不改用其他打印机。

执行者：Codex。此为独立硬件测试样张，正式分拣标签版面尚待实机效果确认后适配。
