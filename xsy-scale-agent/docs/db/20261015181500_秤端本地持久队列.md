# 秤端本地持久队列

日期：2026-10-15。执行者：Codex。仅供 Windows Agent 本机 SQLite 初始化；不修改集团 PostgreSQL，不需要执行平台 Flyway。

程序按下列顺序自动初始化。数据位于配置 DataDirectory（默认当前 Windows 用户 LocalAppData/XSY/ScaleAgent）中的 agent.db。

```sql
PRAGMA journal_mode=WAL;
PRAGMA synchronous=FULL;

CREATE TABLE IF NOT EXISTS events (
  event_key TEXT PRIMARY KEY,
  operation_id TEXT NOT NULL UNIQUE,
  request_hash TEXT NOT NULL,
  payload TEXT NOT NULL,
  raw_frame TEXT NOT NULL,
  state TEXT NOT NULL,
  attempts INTEGER NOT NULL DEFAULT 0,
  next_attempt TEXT NOT NULL,
  event_id TEXT,
  last_error TEXT
);

CREATE TABLE IF NOT EXISTS task_cache (
  session_id TEXT PRIMARY KEY,
  payload TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS settings (
  name TEXT PRIMARY KEY,
  value TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS print_jobs (
  attempt_id TEXT PRIMARY KEY,
  protected_job TEXT NOT NULL,
  execution_id TEXT NOT NULL,
  state TEXT NOT NULL,
  protected_ack TEXT
);

-- 只有上传状态会恢复重试；原始载荷和事件键不改变。
UPDATE events SET state='RETRY_WAIT' WHERE state='UPLOADING';
```

CLAIMED_LOCAL/SPOOL_SUBMITTING 的打印尝试由程序恢复为 ACK_PENDING，冻结 UNKNOWN 回执，绝不重新物理提交。对应任务和回执由当前 Windows 用户 DPAPI 加密，不能换 Windows 用户直接复用。

原始事件和未同步队列不自动删除。本次是首版新建本机数据库，没有生产表 ALTER/DROP。升级时不得删除旧数据库；后续结构变化需要另外设计和验证保留未同步记录的迁移。
