# 秤端触屏工作台

Vue 3 / TypeScript / Vue Router / Vite / Ant Design Vue。遵循上级 `AGENTS.md` 和本模块 `../DESIGN.md`，主题入口为 `src/theme.ts` 与 `src/styles.css`；不引入管理后台路由、登录底座或另一套业务状态机。

- 首页只有按商品/按客户两个入口；`sorting.ts` 组织导航，`TaskList.vue` 复用原列表。按字符串 skuId/customerId 分组，缺失时按 job/item 隔离，不能按名称合并。
- 下级、空态和失效页提供唯一“返回上级”，固定父级或受限本地任务 returnTo，不使用 router.back()。刷新/直接进入仍可返回；触控目标至少 48px。
- 实时秤读数、本地累计、平台已受理与待同步分开。JSON 大 ID/重量用字符串，差额用 decimal.js；当前采样不冒充累计。
- 同源 HttpOnly 工作台会话与 X-Workstation-Request 保护写入，不向浏览器下发 X-Agent-Key。切换员工清空旧视图，迟到请求按代次隔离。
- 实称要求新鲜稳定正 NET；手工入口不依赖秤连接，仍验证授权、已扣皮与格式。市斤别名数值不变，旧记录保留；不做固定量程/分度倍数过滤或舍入。
- 记录并打印/仅记录共享忙状态；一次动作固定 operationId 和选择，未知结果保存原请求，只能原号核对/重试，禁止另起记录或完成。刷新恢复后先确认换筐。
- false 打印选择显示“未要求打印”，无票不可补打；补打沿用保存重量、时间、记录号和链接，不产生新筐。WAITING_CONTRACT 只能显示待同步，SENT 取正式受理结果；TEST_ONLY 和驱动受理不显示真实出纸成功。
- 去皮/置零只提交一次再读状态；断线不清空未确认阻断状态，超时/响应丢失不自动重发。ZERO_OBSERVED 表示收到稳定零值，不伪造硬件 ACK。
- 正式包装标签使用平台返回的身份与公开链接；旧票不使用当前配置回填。人工来源、批次号和 eventKey 分开展示。
- localTest 需结合 hardwareTest 判断是否真实串口/测试纸，预览以原保存模板判定票据模式，不能只看当前运行模式。
- 不加载外部字体、图片或统计；回环和演练禁用 analytics。演练由独立 mock 与目录提供，前端不内置随机任务或正式采样注入入口。
- 默认不测试/构建。授权后由脚本构建并复制 dist 到 Agent wwwroot；浏览器用例显式设置独立演练地址/产物目录，未配置跳过不得报通过，不清空既有业务记录迁就测试。
