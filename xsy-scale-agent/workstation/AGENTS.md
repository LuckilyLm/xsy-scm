# 触屏工作台约束

- 工作台使用 Vue 3、TypeScript、Vue Router 与 Ant Design Vue；主题入口在 `src/theme.ts` 和 `src/styles.css`，不复制管理后台的登录、路由或业务状态机。
- 首页仅展示按商品和按客户两个分拣入口。任务分组、列表、称重和失效状态均提供确定的“返回上级”；直接打开或刷新页面不能依赖浏览器历史。主要触屏按钮至少 48px。
- 页面只接收同源 HttpOnly 会话及 `X-Workstation-Request` 请求头，不向前端提供 `X-Agent-Key`。员工授权仍由平台签发；本地维护码不代替员工身份。
- 任务、商品规格、客户和订单使用正式标识；缺少标识时按原任务隔离，不能凭名称合并。重量与数量保持字符串，用 decimal.js 计算，不让 JavaScript 浮点数决定业务数量。
- 每次人工动作固定 operationId。请求结果未知时保留原请求供核对；补打只追加打印尝试，不新增筐或改变累计。
- `WAITING_CONTRACT` 明确表示等待正式平台接收；`TEST_ONLY` 明确表示演练记录。页面不能把本机保存、驱动入队或模拟平台响应标成正式同步成功。
- 软件控制未确认或设备失联时阻止新采集；前端禁用态与设备服务守卫须一致，不自动重发控制命令。
- 演练数据只由独立 mock 进程与状态目录提供；正式工作台不内置随机任务、模拟重量或正式采样注入入口。
- 构建产物、依赖目录与临时浏览器文件不入 Git。浏览器和设备验证需按根目录 `AGENTS.md` 获得授权，并明确区分源码检查、隔离演练和现场验收。
