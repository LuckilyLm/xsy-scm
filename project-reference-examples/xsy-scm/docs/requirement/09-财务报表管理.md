# 09. 财务报表管理

> 原始需求（摘自 `功能清单模块.docx`）：
> - 经营数据、销售明细、客户订单明细、销售员业绩、采购明细等报表；
> - 已收款、待收款、应付款等报表导出；
> - 单品利润、客户利润报表。

## 1. 功能概述

财务模块负责应收应付的核算与各类经营报表。收入侧来自订单（按实重核算），成本侧来自采购与库存加权平均成本，利润 = 收入 - 成本 - 费用。

## 2. 业务对象

| 对象 | 说明 |
| --- | --- |
| 应收 | 订单产生的客户应收款（已收 / 待收） |
| 应付 | 采购产生的供应商应付款 |
| 收款单 | 客户回款记录（核销应收） |
| 付款单 | 向供应商付款记录（核销应付） |
| 报表 | 经营数据、销售明细、客户订单明细、销售员业绩、采购明细、单品利润、客户利润 |

## 3. 关键字段

### t_receivable（应收）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `receivable_id` | BIGINT | 主键 |
| `receivable_no` | VARCHAR | 应收单号 |
| `order_id` | BIGINT | 订单 |
| `customer_id` / `settle_customer_id` | BIGINT | 客户 / 结算客户（集团结算用） |
| `settle_type` | TINYINT | 结算方式（账期 / 货到付款 / 在线 / 余额） |
| `amount` | DECIMAL(18,2) | 应收金额（订单核算金额） |
| `received_amount` | DECIMAL(18,2) | 已收金额 |
| `balance_amount` | DECIMAL(18,2) | 待收余额 |
| `due_time` | DATETIME | 到期日（按客户账期计算） |
| `status` | TINYINT | 状态（见状态机） |

### t_payable（应付）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `payable_id` | BIGINT | 主键 |
| `payable_no` | VARCHAR | 应付单号 |
| `purchase_id` | BIGINT | 采购单 |
| `supplier_id` | BIGINT | 供应商 |
| `amount` | DECIMAL(18,2) | 应付金额 |
| `paid_amount` | DECIMAL(18,2) | 已付金额 |
| `balance_amount` | DECIMAL(18,2) | 待付余额 |
| `status` | TINYINT | 状态（见状态机） |

### t_payment（收款单）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `payment_id` | BIGINT | 主键 |
| `payment_no` | VARCHAR | 收款单号 |
| `customer_id` | BIGINT | 客户 |
| `amount` | DECIMAL(18,2) | 收款金额 |
| `pay_channel` | TINYINT | 渠道：现金 / 转账 / 在线支付 / 余额扣减 |
| `pay_time` | DATETIME | 收款时间 |
| `proof_image` | VARCHAR | 凭证图片 |
| `status` | TINYINT | 待确认 / 已确认 / 已驳回 |

### 利润核算口径（不单独建表，由报表查询计算）

| 指标 | 计算口径 |
| --- | --- |
| 销售收入 | 订单核算金额（按实重） |
| 销售成本 | 出库数量 × 出库时加权平均成本（来自库存流水） |
| 单品毛利 | 销售收入 - 销售成本 |
| 客户毛利 | 该客户订单收入 - 对应成本 - 该客户相关费用 |
| 毛利率 | 毛利 / 销售收入 |

## 4. 状态机

### 应收状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待收款 | 未收或部分未收 | 部分收款、已结清、已冲销 |
| `PARTIAL` 部分收款 | 已收部分 | 部分收款、已结清 |
| `SETTLED` 已结清 | 全额收清（终态） | 已冲销（退款时） |
| `WRITTEN_OFF` 已冲销 | 退款 / 坏账冲销（终态） | — |

### 应付状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待付款 | 未付或部分未付 | 部分付款、已结清 |
| `PARTIAL` 部分付款 | 已付部分 | 部分付款、已结清 |
| `SETTLED` 已结清 | 全额付清（终态） | — |

### 收款单状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待确认 | 已登记未核销 | 已确认、已驳回 |
| `CONFIRMED` 已确认 | 已核销应收（终态） | — |
| `REJECTED` 已驳回 | 驳回（终态） | — |

## 5. 核心流程

### 5.1 应收生成与收款

1. **订单签收后**生成应收（09-01 已定，见总览 §13），按核算金额写入 `amount`；未签收不生成应收。
2. 按客户账期计算 `due_time`（按金额或按时间）。
3. 客户回款：登记收款单（渠道、金额、凭证）。
4. 财务确认收款 → 核销应收，更新 `received_amount` 与 `balance_amount`。
5. 全额核销后应收转已结清。

### 5.2 应付生成与付款

1. **采购收货入库后**生成应付（09-02 / 05-07 已定，见总览 §13），按实际入库数量与金额计算。
2. 付款登记 → 核销应付 → 已结清。

### 5.3 报表

1. 经营数据：周期内收入、成本、毛利、毛利率。
2. 销售明细 / 客户订单明细：按订单、商品、客户下钻。
3. 销售员业绩：按业务员汇总销售额与毛利。
4. 采购明细：按供应商、商品汇总采购量与金额。
5. 已收款 / 待收款 / 应付款：账龄与余额导出。
6. 单品利润 / 客户利润：按利润口径计算并导出。

## 6. 业务规则与约束

- 金额一律 `DECIMAL(18,2)`，计算用 `BigDecimal`，禁止 `double` / `float`；**所有金额均为不含税金额**（G-02 已定，见总览 §13）。
- 收款 / 付款必须生成流水，**不允许直接修改应收 / 应付余额字段**。
- 应收应付记录不允许物理删除，冲销走 `WRITTEN_OFF` 或反向单据。
- 集团统一结算时，应收挂 `settle_customer_id`（见 02 客户管理）。
- 报表导出需考虑数据量与性能（大数据量走异步导出，待确认 09-05）。
- 数据范围：销售员只看自己客户的业绩；财务看全局。
- 成本口径依赖库存加权平均成本（见 06 库存管理），库存成本异常会直接影响利润报表。
- **G-04 已定**：中间计算保留 4 位，最终金额 `HALF_UP` 四舍五入到分；报表口径必须与订单金额对得上（见总览 §13）。

## 7. 主要接口与页面

- 应收管理：应收列表、账龄、收款登记与核销
- 应付管理：应付列表、付款登记与核销
- 报表中心：经营数据、销售明细、客户订单明细、销售员业绩、采购明细
- 利润报表：单品利润、客户利润
- 导出：已收款 / 待收款 / 应付款导出
