# 02. 客户管理

> 原始需求（摘自 `功能清单模块.docx`）：
> - 客户资料录入、修改、查询；
> - 客户分类型、指定客户显示或屏蔽商品；
> - 下属单位独立采购、集团客户统一结算；
> - 客户绑定供应商、业务员，业务专属推广二维码；
> - 客户账期可按照金额、时间（按月或天）灵活设置。

## 1. 功能概述

客户模块承载客户档案、分级分类、商品可见性、组织结构（集团 / 下属单位）、归属关系（供应商 / 业务员）、推广二维码与账期结算策略。是订单取价、应收结算与数据权限的基础。

## 2. 业务对象

| 对象 | 说明 |
| --- | --- |
| 客户 | 主体档案（个人 / 企业 / 集团） |
| 客户类型 / 分级 | 用于差异化定价与业务策略 |
| 下属单位 | 集团客户下的独立采购单元 |
| 客户-商品可见性 | 指定客户显示或屏蔽某些商品 |
| 客户-供应商 / 业务员 | 归属绑定关系 |
| 推广二维码 | 业务员专属拉新二维码 |
| 客户账期 | 按金额或按时间（月 / 天）的结算周期 |

## 4. 状态机

### 客户状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `POTENTIAL` 潜在 | 登记未合作 | 合作中、黑名单 |
| `COOPERATING` 合作中 | 正常交易 | 暂停合作、黑名单 |
| `SUSPENDED` 暂停合作 | 临时停止交易 | 合作中、黑名单 |
| `BLACKLIST` 黑名单 | 终止合作（终态，可解除需审批） | 合作中 |

### 账期状态

| 状态 | 说明 |
| --- | --- |
| `EFFECTIVE` 生效 | 当前使用 |
| `SUSPENDED` 暂停 | 暂停车载账期，需现结 |

## 5. 核心流程

### 5.1 客户开户

1. 录入客户资料（名称、类型、分级、联系人、地址、坐标）。
2. 设置归属：业务员、绑定供应商（可选）。
3. 设置结算方式（独立 / 集团统一结算）；若为下属单位，指定上级集团与 `parent_customer_id`。
4. 设置账期（按金额或按时间）。
5. 生成业务员专属推广二维码。
6. 审核通过后转为「合作中」。

### 5.2 客户差异化商品可见性

1. 在客户维度配置商品显示 / 屏蔽清单。
2. C 端商城与后台录单时按可见性过滤商品。
3. 屏蔽商品不下单、不参与取价。

### 5.3 集团统一结算

1. 下属单位各自下单采购（订单归属本单位）。
2. 应收挂账到上级集团客户。
3. 集团统一对账与收款，冲销下属单位应收。
4. 报表可按集团 / 下属单位两个维度统计。

## 6. 业务规则与约束

- 金额字段 `DECIMAL(18,2)`，禁止 `double` / `float`。
- 账期修改必须留审计日志（客户账期修改属 `AGENTS.md` 明列的审计项）。
- 数据范围：业务员仅可查看 / 维护自己的客户（复用 `@DataScope`）。
- 客户删除为逻辑删除；存在未结清应收的客户不允许停用或拉黑。
- 余额充值结算时，扣减 `balance` 必须生成财务流水，不允许直接改余额字段。
- 推广二维码归属业务员，扫码注册的新客户自动绑定该业务员。
- 坐标字段用于物流配送线路规划，需与配送模块对齐（见 08 物流配送）。

## 7. 主要接口与页面

- 客户列表：多条件查询、分级筛选、归属筛选
- 客户详情：资料、账期、可见商品、绑定关系、二维码
- 账期设置：按金额 / 按时间配置与生效记录
- 集团客户树：上级与下属单位关系维护
- 客户对账入口（与财务模块联动）
