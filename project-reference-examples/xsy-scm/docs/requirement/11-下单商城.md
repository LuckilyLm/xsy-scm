# 11. 下单商城（微信公众号 / 小程序）

> 原始需求（摘自 `功能清单模块.docx`）：
> - 定制首页、设置抢购促销活动、新品推荐版块；
> - 商品搜索、常用菜品、分类下单、购物车、再来一单、智能语音下单；
> - 四种结算方式：账期支付、货到付款、在线支付、余额充值；
> - 下游客户查看下单商品汇总等数据报表。
> - 支持不同风格的商城主题。

## 1. 功能概述

下单商城是面向**下游客户（C 端 / 小 B）**的自助下单入口，载体已定：**微信小程序为主，同一套 `xsy-app`（UniApp Vue3）代码同时发布 H5**（G-06，见总览 §13）。运营侧配置（首页、活动、新品推荐、主题）归属 [03-营销管理.md](./03-营销管理.md)，本模块聚焦 C 端交互与下单闭环。

## 2. 业务对象

| 对象 | 说明 |
| --- | --- |
| 商城客户 | 登录态客户（关联客户档案，见 02 客户管理） |
| 首页 | 轮播 / 活动楼层 / 新品推荐（后台配置渲染） |
| 商品浏览 | 搜索、分类、商品详情 |
| 常用清单 | 客户常购商品（常用菜品） |
| 购物车 | 临时选购 |
| 订单 | 商城下单产生的订单（复用 04 订单管理） |
| 商城报表 | 下游客户查看自己的下单汇总 |
| 主题 | 多套商城风格配置 |

## 4. 状态机

### 首页 / 主题状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `DRAFT` 草稿 | 配置中 | 已发布 |
| `PUBLISHED` 已发布 | 线上生效 | 已下线 |
| `OFFLINE` 已下线 | 停止使用 | 已发布 |

### 商城订单状态

复用订单状态机（见 04 订单管理），商城侧关注以下展示态：

| 展示态 | 对应订单状态 |
| --- | --- |
| 待付款 | 待确认（在线支付未付） |
| 待发货 | 已确认 / 采购中 / 待分拣 |
| 待收货 | 分拣中 / 配送中 |
| 已完成 | 已签收 / 已完成 |
| 售后中 | 退款中 |

## 5. 核心流程

### 5.1 客户登录与首页

1. 客户通过公众号 / 小程序授权登录，绑定客户档案。
2. 首页按后台装修渲染：轮播、抢购活动、新品推荐、分类入口。
3. 主题按配置渲染（支持多套风格）。

### 5.2 浏览与下单

1. 商品搜索 / 分类浏览 / 常用清单快速加购。
2. 商品详情展示：规格、价格（按客户分级 / 协议价取价）、库存状态。
3. 加入购物车 → 确认 → 选择结算方式（账期 / 货到付款 / 在线支付 / 余额充值）。
4. 提交订单 → 价格写入快照 → 进入订单履约流程。

### 5.3 再来一单 / 语音下单

1. 再来一单：选历史订单重建购物车，失效商品提示剔除。
2. 语音下单：语音识别转商品与数量，需提供手工修改与确认步骤（识别失败降级为手工录入）。

### 5.4 客户数据报表

1. 客户查看自己的下单汇总：按时间、商品、金额统计。
2. 支持导出或在线查看（口径待确认 11-04）。

## 6. 业务规则与约束

- **价格快照**：商城下单同样锁定成交价，后续改价不影响已提交订单。
- 金额 `DECIMAL(18,2)`，重量 `DECIMAL(18,3)` kg。
- 商品可见性：按客户显示 / 屏蔽配置过滤，屏蔽商品不展示、不可下单。
- 库存联动：可售库存不足时限制下单，防止超卖（见 06 库存管理）。
- 在线支付需防重复提交与回调幂等。
- 余额支付必须生成财务流水，不允许直接改 `balance`。
- C 端只能查看自己的数据（数据范围强校验）。
- 不得在前端硬编码 API 地址，走 Vite env 配置。
- 语音下单为增强能力，必须保留手工下单通道。

## 7. 主要接口与页面

- 首页：装修渲染、活动楼层、新品推荐
- 商品：搜索、分类、详情、常用清单
- 购物车与结算：加购、结算方式选择、提交订单
- 订单：列表、详情、再来一单、取消、售后
- 我的：余额、账期、下单汇总报表、主题切换
