# 06. 库存管理

> 原始需求（摘自 `功能清单模块.docx`）：
> - 实际重量入库、出库、盘点、报损、报溢、多规格转换等；
> - 库存和商城商品、订单联动、库存阈值预警；
> - 支持进价加权平均核算，成本准确。

## 1. 功能概述

库存是供应链的成本与履约中枢。所有出入库行为都必须沉淀为**流水**，余额由流水汇总推导，成本采用**进价加权平均**。库存同时与商城商品（可售）、订单（占用 / 扣减）联动。

## 2. 业务对象

| 对象 | 说明 |
| --- | --- |
| 库存余额 | 按商品 / 规格（+ 仓库）维度的当前结存 |
| 库存流水 | 每一次出入库的明细记录 |
| 盘点单 | 周期或临时盘点 |
| 报损 / 报溢单 | 损耗与溢余处理 |
| 规格转换单 | 多规格之间换算（如整件拆零） |
| 阈值预警 | 库存上下限告警配置与触发 |

## 4. 状态机

### 库存流水方向

| 值 | 说明 |
| --- | --- |
| `IN` 入 | 增加结存 |
| `OUT` 出 | 减少结存 |

### 盘点单状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待盘点 | 已创建 | 盘点中、已取消 |
| `CHECKING` 盘点中 | 录入实盘数据 | 已完成 |
| `COMPLETED` 已完成 | 差异已调整并生成流水（终态） | — |
| `CANCELLED` 已取消 | 取消盘点（终态） | — |

### 报损 / 报溢单状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待审核 | 提交申请 | 已完成、已驳回 |
| `COMPLETED` 已完成 | 生成流水（终态） | — |
| `REJECTED` 已驳回 | 审核不通过（终态） | — |

### 预警状态

| 状态 | 说明 |
| --- | --- |
| `NORMAL` 正常 | 在阈值区间内 |
| `LOW` 低于下限 | 触发补货预警 |
| `HIGH` 高于上限 | 触发积压预警 |

## 5. 核心流程

### 5.1 采购入库

1. 采购收货登记（见 05 采购管理）。
2. 库存业务层生成入库流水（记录数量、实重、单价、变动前后）。
3. 实时重算加权平均成本（06-04 已定）：
   `新均价 = (原结存成本 + 本次入库金额) / (原结存数量 + 本次入库数量)`
4. 更新余额（数量、重量、均价、总成本）。

### 5.2 销售出库（订单发货 / 分拣）

1. 订单分拣完成，按实重生成出库流水。
2. 库存业务层扣减余额，成本按当前加权平均价结转。
3. 数量不足时触发异常（欠发 / 待采）。

### 5.3 盘点

1. 创建盘点单（全盘 / 抽盘），冻结或快照当前账面数量。
2. 录入实盘数量与重量。
3. 计算差异，生成盘点调整流水（盘盈 / 盘亏）。
4. 审核通过后更新余额，差异金额进入财务核算。

### 5.4 报损 / 报溢

1. 发起报损或报溢单，填写数量、重量与原因。
2. 审核通过 → 生成出库（报损）或入库（报溢）流水。
3. 更新余额；报损金额进入成本核算。

### 5.5 规格转换

1. 选择源规格与目标规格（如整件 → 散装）。
2. 按折算关系生成「转换出」与「转换入」两条流水。
3. 保持总重量 / 总成本守恒，重算目标规格均价。

### 5.6 阈值预警

1. 按商品 / 规格配置上下限（当前**单仓库**，无需按仓库分别配置）。
2. 余额变动后校验，触发 `LOW` / `HIGH`。
3. 预警推送采购（补货）与销售（积压处理）。

## 6. 业务规则与约束

- **余额 + 流水**：任何模块不得自行 `UPDATE` 库存余额，必须走库存业务层（遵循 `AGENTS.md` 铁律）。
- 所有出入库必须生成流水，流水记录变动前后的数量与加权平均成本，保证可追溯。
- 重量 `DECIMAL(18,3)` kg，数量 `DECIMAL(18,3)`，单价 / 均价 `DECIMAL(18,4)`，金额 `DECIMAL(18,2)`。
- 盘点、报损、报溢必须留审计日志（`AGENTS.md` 明列）。
- 库存流水不允许物理删除，冲销使用反向流水。
- 出库不得导致结存为负（是否允许负库存待确认 06-03）。
- **06-04 已定**：加权平均成本在**每次入库时实时重算**，不做日终批处理（见总览 §13）。
- 成本重算需考虑并发（同一商品并发出入库时的加锁策略）。
- 与商城联动：可售库存变化时同步 C 端展示，防止超卖。
- **G-03 已定**：单仓库、不启用批次与保质期；出入库不指定批次，`warehouse_id` / `batch_id` 字段保留备用（见总览 §13）。

## 7. 主要接口与页面

- 库存查询：按商品 / 规格 / 仓库查询余额与成本
- 库存流水：多维度查询与导出
- 盘点：创建、录入、差异调整
- 报损报溢：申请、审核、流水
- 规格转换：转换单与守恒校验
- 预警配置与预警列表
