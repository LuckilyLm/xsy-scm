# 07. 分拣管理

> 原始需求（摘自 `功能清单模块.docx`）：
> - 按单品或客户订单两种分拣方式；
> - 实重分拣打印等功能，重量实时上传系统；
> - 非标品分拣、分拣误差阈值设定、标品一键分拣打印；
> - 按分拣员、送货时间、线路、供应商筛选分拣任务，供应商代分拣。

## 1. 功能概述

分拣是「按订单把货配齐」的环节，直接产生实际重量并驱动出库与订单核算。核心是**两种分拣模式**（按单品汇总拣 / 按客户订单拣）、**实重实时上传**与**标签打印**。

## 2. 业务对象

| 对象 | 说明 |
| --- | --- |
| 分拣任务 | 一次分拣作业的主单（可按线路 / 供应商 / 分拣员分派） |
| 分拣明细 | 按单品或按订单的具体拣货项 |
| 分拣记录 | 实拣重量 / 数量的执行结果 |
| 分拣标签 | 打印的标签（含客户、商品、重量、二维码） |
| 误差阈值 | 非标品允许的称重偏差配置 |

| 字段 | 类型 | 说明 |

| `threshold_weight` | DECIMAL(18,3) | 允许误差绝对值（kg） |

## 4. 状态机

### 分拣任务状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待分拣 | 任务已生成 | 分拣中、已取消 |
| `SORTING` 分拣中 | 执行中 | 已完成、已取消 |
| `COMPLETED` 已完成 | 实拣完成并生成出库流水（终态） | — |
| `CANCELLED` 已取消 | 取消分拣（终态） | — |

### 分拣明细状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待拣 | 未拣 | 已拣、缺货 |
| `SORTED` 已拣 | 已实拣 | — |
| `SHORTAGE` 缺货 | 库存不足无法拣（终态处理） | 待拣（补货后重拣） |

## 5. 核心流程

### 5.1 生成分拣任务

1. 按条件筛选待分拣订单（分拣员、送货时间、线路、供应商）。
2. 选择分拣方式：
   - **按单品**：跨订单汇总同一商品，一次拣出再分配到各订单（效率高）。
   - **按客户订单**：逐单拣货，直接装箱（准确性高）。
3. 生成分拣任务与明细，分配分拣员（或供应商代分拣）。

### 5.2 实重分拣与打印

1. 分拣员按明细拣货，称重设备读取实重（或手工录入）。
2. 实重实时上传系统，写入 `actual_weight`。
3. 打印分拣标签（客户、商品、重量、二维码）。
4. 标品支持**一键分拣打印**（按应拣数量直接生成标签，无需逐个称重）。

### 5.3 误差校验与完成

1. 计算 `diff_rate`，与误差阈值比较。
2. 超阈值时标记 `over_threshold_flag`，需确认或重拣。
3. 全部明细完成 → 任务转已完成。
4. 生成**库存出库流水**（走库存业务层），回写订单明细实重与核算金额。

## 6. 业务规则与约束

- 实重必须实时回写订单明细，驱动订单核算（见 04 订单管理）。
- 出库必须生成库存流水，禁止直接改库存余额（遵循 `AGENTS.md`）。
- 重量 `DECIMAL(18,3)` kg，数量 `DECIMAL(18,3)`。
- 非标品必须称重；标品可一键分拣但需保留实际数量记录。
- 缺货明细不得静默跳过，必须标记并回传采购 / 客服。
- 供应商代分拣需做数据权限隔离，仅能看到分配给自己的任务。
- **G-05 已定**：一期实重**手工录入**，预留称重设备对接接口，并保留手工录入降级通道（见总览 §13）。

## 7. 主要接口与页面

- 分拣任务列表：按分拣员 / 送货时间 / 线路 / 供应商筛选
- 分拣执行页：明细、称重录入、标签打印、缺货标记
- 阈值配置：按商品 / 全局配置误差
- 分拣报表：分拣效率、误差统计、缺货统计
