# 01. 商品管理

> 原始需求（摘自 `功能清单模块.docx`）：
> - 商品三级分类，商品详情、图片等可批量修改上传；
> - 不同类型客户不同定价、商品时价、协议价、批量修改单价；
> - 支持标品、非标品、多规格、多供应商；
> - 商品可按照自采、供应商送货默认设定采购员或供应商。

## 1. 功能概述

商品是供应链主链路的基础数据，承载分类、规格、图片、价格体系与采购来源设定。核心难点在于**多价格体系**（客户分级价 / 时价 / 协议价）与**标品非标品混合计量**。

## 2. 业务对象

| 对象 | 说明 |
| --- | --- |
| 商品分类 | 三级树形分类（一级 > 二级 > 三级） |
| 商品 SPU | 商品主体，承载详情、图片、计量方式 |
| 商品 SKU | 规格维度组合（多规格），非标品可无 SKU 或仅单规格 |
| 商品价格 | 基础价 / 客户分级价 / 时价 / 协议价，含生效时间 |
| 商品-供应商 | 多供应商关系与默认供应商 |
| 商品-采购设定 | 自采或供应商送货，默认采购员 / 供应商 |

## 4. 状态机

### 商品状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `DRAFT` 草稿 | 新建未完善 | 待上架、作废 |
| `PENDING` 待上架 | 信息完整待审核 | 已上架、草稿 |
| `ON_SALE` 已上架 | 正常销售，C 端可见 | 已下架 |
| `OFF_SALE` 已下架 | 暂停销售 | 已上架 |
| `INVALID` 已作废 | 终止使用（终态） | — |

### 价格状态

| 状态 | 说明 |
| --- | --- |
| `EFFECTIVE` 生效 | 当前生效价格 |
| `EXPIRED` 失效 | 过期或被新价替换（终态） |

## 5. 核心流程

### 5.1 商品创建与上架

1. 录入商品基础信息（分类、类型、计量方式、采购方式）。
2. 配置规格（多规格生成 SKU；非标品登记单位与折算重量）。
3. 上传详情与图片（支持批量）。
4. 设置价格（基础价，按需设置分级价 / 时价 / 协议价）。
5. 绑定供应商与默认采购员。
6. 提交审核 → 上架；上架后 C 端商城可见。

### 5.2 批量修改

1. 选择商品（支持按分类批量筛选）。
2. 批量修改：详情、图片、单价、状态、分类。
3. 提交后写入审计日志（修改前后值）。
4. 价格类修改按生效时间生效，不影响历史订单（订单价格用快照）。

### 5.3 客户差异化定价

1. 客户分级（见客户管理）或指定客户。
2. 为该分级 / 该客户设置分级价或协议价。
3. 下单时按**已定优先级**取价：**协议价 > 促销价 > 分级价 > 时价 > 基础价，不叠加**（01-01 已定，见总览 §13）。
4. 取价结果写入订单快照，后续改价不影响已生成订单。

## 6. 业务规则与约束

- 金额 / 重量 / 数量精度遵循 `00-总览与通用约定`：单价 `DECIMAL(18,4)`，重量 `DECIMAL(18,3)` kg。
- **所有金额均为不含税金额**（G-02 已定，见总览 §13）。
- 非标品必须支持按重计量，且需登记单位折算重量以便与库存（kg）换算。
- 价格变更必须留审计日志；时价按生效时间生效，系统取「生效时间 ≤ 当前时间」的最新价。
- 商品下架后不影响已有订单履约，仅限制新增下单。
- 商品删除为逻辑删除；已被订单 / 采购单引用的商品不允许作废。
- 图片上传复用 SmartAdmin 文件服务，禁止业务表硬编码永久公网 URL。
- 批量操作必须支持失败明细回显，不允许部分成功却提示全部成功。

## 7. 主要接口与页面

- 分类管理：树形增删改、排序、启用停用
- 商品列表：多条件查询、批量修改、上下架、导入导出
- 商品详情：基础信息、规格、图片、价格、供应商
- 价格管理：分级价 / 时价 / 协议价维护与生效记录
- 接口命名遵循 `AGENTS.md`：复制现有 Controller 的动作式 URL 风格
