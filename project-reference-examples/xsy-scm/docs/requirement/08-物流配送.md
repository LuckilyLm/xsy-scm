# 08. 物流配送

> 原始需求（摘自 `功能清单模块.docx`）：
> - 根据客户区域、配送时间、订单数量、金额线路规划；
> - 线路内订单分布可视、线路轨迹记录；
> - 线路发货单一键打印。

## 1. 功能概述

配送把分拣完成的货物按线路送达客户。核心是**线路规划（多维度）**、**线路可视化与轨迹记录**、**发货单一键打印**，并以签收结果驱动订单完成与应收确认。

## 2. 业务对象

| 对象 | 说明 |
| --- | --- |
| 线路 | 一次配送路线（含区域、司机、时间） |
| 线路订单 | 线路内的订单集合 |
| 配送任务 / 发货单 | 面向客户的配送单据（可打印） |
| 司机 / 配送员 | 执行人 |
| 轨迹 | GPS 位置记录 |
| 签收 | 客户签收结果（含异常） |

## 4. 状态机

### 线路状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `PENDING` 待规划 | 已创建未排线 | 已规划、已取消 |
| `PLANNED` 已规划 | 线路与订单已确定 | 配送中、已取消 |
| `DELIVERING` 配送中 | 司机出车配送 | 已完成 |
| `COMPLETED` 已完成 | 全部订单配送完毕（终态） | — |
| `CANCELLED` 已取消 | 取消线路（终态） | — |

### 配送 / 订单配送状态

| 状态 | 说明 | 可流转到 |
| --- | --- | --- |
| `WAITING` 待配送 | 已装车待送 | 配送中 |
| `DELIVERING` 配送中 | 在途 | 已签收、异常 |
| `SIGNED` 已签收 | 客户正常签收（终态） | 异常（事后申诉） |
| `EXCEPTION` 异常 | 拒收 / 部分签收 / 无法送达 | 已签收（重新配送后）、已退回 |

## 5. 核心流程

### 5.1 线路规划

1. 筛选待配送订单（已分拣完成）。
2. 按维度规划线路：**客户区域**、**配送时间**、**订单数量**、**订单金额**（可加权）。
3. 系统辅助或人工编排配送顺序 `seq`。
4. 生成线路与线路订单，指定司机与车辆。

### 5.2 发货与配送

1. 按线路**一键打印发货单**（含客户、商品、实重、金额、顺序）。
2. 司机接单出车，线路转配送中。
3. 配送过程记录 GPS 轨迹。
4. 线路内订单分布可视化（地图 / 列表展示配送进度）。

### 5.3 签收与异常处理

1. 到达客户处签收：记录签收人、实收重量、签收图片。
2. 异常（拒收、部分签收）记录原因与图片，回传客服。
3. 签收结果驱动：订单转已签收 → 已完成；异常走退款 / 退回流程。
4. 货到付款订单在签收环节收款，生成收款记录。

## 6. 业务规则与约束

- 重量 `DECIMAL(18,3)` kg，金额 `DECIMAL(18,2)`。
- 配送状态修改必须留审计日志（`AGENTS.md` 明列）。
- 签收图片复用文件服务，禁止硬编码公网 URL。
- 轨迹数据量大，需考虑存储周期与采样频率（待确认 08-04）。
- 数据范围：司机仅可查看自己的线路。
- 异常签收必须联动订单与财务（退款 / 应收调整），不得孤立处理。
- 线路调整（增删订单）需记录原因，避免配送责任不清。

## 7. 主要接口与页面

- 线路规划：待配送订单池、多维度筛选、顺序编排
- 线路列表与详情：订单分布、轨迹回放、进度
- 发货单打印：一键批量打印
- 签收：移动端签收（实重、图片、异常上报）
- 配送报表：准时率、异常率、线路成本
