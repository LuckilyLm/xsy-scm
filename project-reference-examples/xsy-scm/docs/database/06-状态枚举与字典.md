# 06. 状态枚举与字典

> 本文件是 P0 主链路的**状态枚举唯一来源**。数据库字段 `COMMENT`、后端 Java Enum、前端常量必须三者一致。
> 遵循 `AGENTS.md`：状态一律使用 Enum，禁止业务代码散落 `0/1/2` 字面量。
> 状态值新增 / 修改时，必须同步更新本文件、数据库注释、后端 Enum、前端常量、API 文档。

## 7. 后端 Enum 约定与骨架

### 7.1 约定

- 枚举类命名：`{业务}Enum`，如 `OrderStatusEnum`。
- 每个枚举提供 `value`（数据库值）与 `desc`（中文描述），并提供 `valueOf(Integer)` 静态方法。
- 禁止在业务代码中使用字面量判断状态，一律引用枚举。
- 枚举变更必须同步：数据库字段 `COMMENT`、本文件、前端常量。

### 7.2 骨架示例

```java
package com.xsy.scm.business.order.constant;

import lombok.AllArgsConstructor;
import lombok.Getter;

/**
 * 订单状态
 *
 * 数据库字段：t_order.status
 * 注意：修改取值时必须同步更新数据库注释、docs/database/06-状态枚举与字典.md 与前端常量
 */
@Getter
@AllArgsConstructor
public enum OrderStatusEnum {

    DRAFT(1, "草稿"),
    PENDING(2, "待确认"),
    CONFIRMED(3, "已确认"),
    PURCHASING(4, "采购中"),
    SORTING(5, "待分拣"),
    SORTED(6, "分拣中"),
    DELIVERING(7, "配送中"),
    SIGNED(8, "已签收"),
    COMPLETED(9, "已完成"),
    REFUNDING(10, "退款中"),
    CANCELLED(11, "已取消"),
    INVALID(12, "已作废"),
    ;

    private final Integer value;
    private final String desc;

    public static OrderStatusEnum valueOf(Integer value) {
        if (value == null) {
            return null;
        }
        for (OrderStatusEnum item : values()) {
            if (item.value.equals(value)) {
                return item;
            }
        }
        return null;
    }
}
```

> 实际落地时按项目现有 Enum 工具与基类风格调整（优先复用 SmartAdmin 已有枚举机制与 `value → label` 能力）。
