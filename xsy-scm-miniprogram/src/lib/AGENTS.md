# 小程序基础能力

- 页面登录检查由 login-guard 集中维护，所有导航方式与页面 onShow 共用。公开页名单要与实际公开接口一致；新业务页默认需要登录。
- 请求层不依赖用户 Store，避免 Store → API → 请求层的循环依赖；有本地令牌时由服务端校验，无令牌时不发送需登录的请求。
- 登录提示与跳转共用去重状态；已登录新会话不能被旧请求的失效响应清除。
- 扫码或冷启动进入首页、我的时，首个页面路径就绪后立即检查本地令牌；无令牌直接进入登录页，不等待接口或提示延时。App onShow 早于页面初始化时不能提前消耗这次启动检查。
- App onShow 每次重做入口检查，覆盖微信复用后台页面的再次扫码；保留本地令牌的会话交给服务端验证。
