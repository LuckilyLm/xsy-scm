# 我的页面

- 页头与首页共用已发布顶部渐变及可读前景，通过useMallTheme的header模式同步可见页原生前景；浅色背景用深色身份文字，不能继续写死绿色背景或白字。主体底色与首页共用商城页面底色。

- 未登录时头像旁只显示一行“登录后查看客户信息”，点击页头进入登录页，不叠加“未登录”标题或独立登录按钮。
- 已登录时客户名称读取统一用户状态；页头身份内容避开微信胶囊，优惠入口和需要身份的功能继续遵循各自登录守卫。
- 页头不显示手机号，点击头像进入受登录保护的个人资料页；手机号和客户名称仅读取当前用户状态，不开放自助修改。
- 业务入口直接导航到目标页，由公共守卫统一提示并拦截未登录访问；头像提示是明确的登录入口，可直接进入登录页。
- 功能与优惠插画从MinIO加载，统一使用XsyRemoteImage保持尺寸和失败占位；导航图标仍为本地文件，图片失败不影响入口文字和点击。
