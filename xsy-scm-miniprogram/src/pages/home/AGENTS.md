# 首页

- 顶部使用DESIGN.md的home-header模式：默认浅绿白渐变、深色地址、白底细绿边胶囊搜索及右侧搜索按钮，不增加独立店铺标题。顶部起止色读取当前发布配置，缺失时回退MALL_HOME_COLORS；不与主题主色绑定。
- 状态栏与微信胶囊按公共布局数据避让；定位行及滚动阅读栏高度使用navBarHeight，不固定状态栏或胶囊位置。搜索高44px、左右16px，点击仍进入搜索页；滚动阅读导航继续读取公开店铺配置。
- 搜索按钮视觉36px、点击区44px；地址文字和原生前景按两端颜色选择可读颜色。仅首页可见时同步原生前景，后台刷新颜色不能覆盖其他页面导航。
- 首页底色为浅灰绿，Banner左右16px、圆角12px，分类与快捷区连接成白色内容面；保留正式内容顺序、图片比例及点击事件。
- 分类与快捷插画走MinIO，营销图继续读正式发布配置；共用XsyRemoteImage保留原尺寸及断图兜底，不依赖图片加载结果决定导航行为。
- 未登录仅展示首页公开外壳，不请求客户商品、分类、地址或装修内容；资料恢复或登录成功后重新加载。搜索、分类与业务快捷入口统一经过登录守卫。
- 扫码或冷启动进入首页时由公共守卫立即检查本地令牌，无令牌直接进入登录页；页面自身的未登录展示仅用于身份变化或后续导航时的兜底。
