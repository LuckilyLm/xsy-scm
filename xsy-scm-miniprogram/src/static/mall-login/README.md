# 登录交付素材

来自用户交付优化素材包的登录页拆分图。主视觉、Logo、底部波浪、手机号、密码、提示和密码隐藏图标分别用于真实登录组件，不将整页参考图放进正式页面。

本目录仅保留随包发布的Logo、微信及表单小图；主视觉与波浪移至media/mall-login，通过MinIO在线加载。`sources.json`记录来源分组、规范化业务文件名、原图SHA-256及文件体积，不保留生成工具名、时间戳文件名或提示词元数据。品牌Logo保持原色，登录动作使用商城主题变量。字体与输入校验沿用页面和正式账号接口。

`wechat.webp` 来自用户另行交付的“微信.svg”，使用96像素透明图的无损WebP，解码RGBA与原PNG一致，保留原绿色与轮廓；来源哈希记录在同一清单。该图标放在密码登录按钮下方，由真实微信手机号授权按钮承接点击。
