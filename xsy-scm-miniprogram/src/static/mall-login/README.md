# 登录交付素材

来自用户交付优化素材包的登录页拆分图。主视觉、Logo、底部波浪、手机号、密码、提示和密码隐藏图标分别用于真实登录组件，不将整页参考图放进正式页面。

仅按现有透明通道裁除可见区域外留白、缩放并压缩为PNG；原图名称、SHA-256及副本体积见 `sources.json`，PNG中也保留来源元数据。品牌Logo与插画保持原色，登录动作使用商城主题变量。字体与输入校验沿用页面和正式账号接口。

`wechat.png` 来自用户另行交付的“微信.svg”，仅转换为96像素透明PNG以供原生小程序使用，保留原绿色与轮廓；来源哈希记录在同一清单。该图标放在密码登录按钮下方，由真实微信手机号授权按钮承接点击。
