# 确认订单

- index.vue编排地址、购物车、配送仓和服务端试算；无地址仍应显示正式预估金额，提交必须有地址及可用配送仓。
- 自动选券统一调用utils/checkout-preview.js，完整分页并限制候选并发；只比较服务端完整优惠后应付的四位定点金额，不复制后端优惠公式。手动选择或明确不用券优先，手动券失效时说明原因并重新按不用券试算。
- 资料加载和试算分别按请求序号丢弃旧响应；加载或试算失败后禁止沿用旧金额及价格指纹提交，错误处提供重试。
- 备注由原生adjust-position避让，聚焦或键盘显示时隐藏底栏，离开页面清理输入状态并使未完成请求失效。
- 底栏以v-if移除，不能改为v-show：微信原生hidden与底栏display:flex组合时仍可能显示并占位。
