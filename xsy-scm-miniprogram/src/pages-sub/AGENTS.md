# 业务分包

- 按钮、链接和功能图标通过useMallTheme读取已发布主色或ink，不导入固定COLOR_PRIMARY或写死品牌绿；成功、警告、错误和收支状态保持语义色。季节预设更新后，返回页面时读取同一主题，不另建分包主题缓存。

- pages.json以pages-sub作为普通业务分包根目录；页面继续按商品、地址、订单、售后等子目录组织，公开页面路径不变。
- 仅业务分包使用的接口、状态映射和组合函数放在shared对应目录；主包页面不得引用shared。普通分包可读取主包共享逻辑，主包不得反向依赖业务分包。
- 基础请求、登录、主题、用户状态和导航仍在主包。跨业务页复用代码直接在同一业务分包内共享，不使用构建后搬移或自定义分包插件。
- 修改分包配置或共享代码位置后运行tools/verify-package.mjs，检查主包可达性、模块引用和每包体积，并在微信工具核验相应业务页。
