# 我的页面交付素材

来自用户交付“我的”目录，共10张功能PNG：订单、购物车、地址、售后、溯源、公告、关于我们、条款、售后规则和密码。保留交付PNG字节、自带浅绿圆角底面及透明轮廓，通过MinIO在线加载，不进入代码包。

来源分组、规范化业务文件名、原图SHA-256及体积见sources.json，原始交付图片按哈希核对。路径集中在constants/mall-visual-const.js，入口仍读取真实账号状态并使用正式路由，不将整张参考图作为页面背景或点击区域。未交付专属图片的配置入口继续使用既有功能图标。

“我的优惠券”另用单独交付的“我的优惠券图标.png”，收紧透明留白后缩放为128像素PNG，和领券入口共用显示尺寸。该记录的sourcePackage为“独立交付素材”，区别于前10张目录素材。
