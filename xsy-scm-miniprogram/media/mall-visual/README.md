# 商城轻3D素材

优化交付包覆盖了13张二级分类（含新增鱼虾专用映射）、活动专区及暂无商品/网络异常图片；其余沿用完整45张交付包。`sources.json` 的 `sourcePackage` 为“优化素材”时指向优化包，其余记录沿用原包。本目录保留已交付PNG的原始字节，不再为代码包压缩图片。

来源：用户提供的“鲜蔬源SCM小程序完整视觉素材_45张”。来源SHA-256及映射见sources.json，当前文件摘要见上级manifest.json。图片发布到MinIO在线加载，本目录不进入代码包；文字由界面呈现。营销横幅使用正式文件服务配置。

分类插画仅用于导航，不能代替真实商品照片；不按素材名称自动创建业务分类。未知分类使用现有功能图标。

活鲜、水产和鱼类共用fish-shrimp，水果与调味的相近插画分别共用fruit和seasoning；保留20张有区分作用的分类代表图，当前分类、快捷及空状态清单共33张。退役图片移出media，不再发布新的资源副本；页面分类名称和商品目录不受图片合并影响。

收货地址空状态另用用户单独交付的绿色配送地址插画，去除四周透明留白后缩放为240像素，保留透明背景和原色；来源及原图哈希同样记录在sources.json。
