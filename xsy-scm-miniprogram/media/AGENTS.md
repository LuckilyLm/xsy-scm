# 线上插画原图

- 本目录位于src之外，不参与小程序代码包复制；保存分类、功能、空状态插画及登录装饰原始PNG，不为代码包指标压缩原图。
- 各组sources.json记录交付来源；manifest.json记录当前文件字节数、SHA-256和资源目录摘要。变更图片时核对原图后更新清单，再发布新的摘要目录。
- 使用tools/upload-media.py上传到已有公开图片桶的public/image/mall-ui目录，匿名校验原图摘要。凭据仅从环境读取，不写入源码、清单或前端配置。
- 导航、Logo及表单微型图标保持src/static本地路径；营销、商品与正式说明继续由后台接口维护。
