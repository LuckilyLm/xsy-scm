# 微信小程序工作区

沿用根目录 AGENTS.md；本文件仅补充小程序工程操作约定。

- 正式源码在 `src/`，离线演示实现位于 `mock/`。真实联调保持 mock 关闭，不将演示数据当作后端验收。
- 源码检查的正则使用明确的空白量词；保持后端枚举、客户端映射及未知值回退的断言，不能为格式检查移除业务覆盖。
- API 环境配置、编译产物目录及微信工具导入方式统一见本目录 `README.md` 的“开发”，修改启动链路时同步维护该说明。
- 微信工具的 `project.config.json`、`project.private.config.json` 与 `.env.local` 是被 Git 忽略的本机配置。修改前读取现值，保留用户 AppID 和无关设置。
- 更换正式微信凭据时，核对源码manifest、工具project.config与后端XSY_WECHAT_APP_ID一致，并验证模拟器实际AppID；AppSecret仅配置后端，不能写入小程序或素材清单。
- 诊断地址问题时，对照磁盘编译产物和模拟器实际请求；仅刷新成功不能证明新产物已经运行。按需清理编译缓存，保留用户登录与本地存储。
- 小程序页面与交互验收使用微信开发者工具实际运行，不用浏览器H5结果代替。Windows调用工具CLI时使用与已打开项目一致的原生规范路径；模板绑定错位时核对实际页面data与磁盘WXML，清理file和compile缓存后完整编译，保留storage。
- 登录拦截集中在 `src/lib/login-guard.js`：扫码或冷启动进入首页、我的时，无本地令牌立即进入登录页；登录、公开说明和溯源入口保持可用。后续进入业务页缺少令牌时先提示“请先登录”再进入登录页。导航拦截和页面显示检查共用该规则，请求层同时阻止匿名发送需登录的接口；公开接口显式声明 anonymous。已有本地令牌由服务端验证，不用尚未恢复的用户资料判断未登录。
- Docker 联调先检查 `docker ps` 的实际端口与代理路由，不用源码开发端口推断容器不可用。验证既要检查 HTTP 状态，也要检查响应信封的 `code` 与 `ok`。
- 分类图标由商品分类后台选择交付PNG或上传公开图片，首页和分类页通过src/utils/category-icon.js读取节点iconUrl，不再按名称匹配或继承父级图片；未配置时显示标准功能图标。图片经MinIO在线加载，不着色、不生成SVG或emoji。后台可选图标的来源与原图哈希在web的assets/category-icons/sources.json。
- 商城大插画在media保留交付PNG，本地仅保留导航、Logo和表单小图；不要并行维护另一套分类图标或遗留图标包。后台手机预览复用同源素材，清理旧资源前先核对引用并按根目录规则移入delete。
- 底部导航的5组普通/选中交付PNG维护在src/static/mall-navigation并随包发布，我的功能PNG维护在media/mall-profile并在线加载；映射集中在mall-visual-const，各组sources.json保留来源分组、规范化业务文件名与原图SHA-256，交付原图按哈希核对；清单和PNG元数据不保留生成工具名、时间戳文件名或提示词。导航图标按active切换并保留原色，文字仍随主题；固定高度与安全区不变。我的图片自带浅绿圆角底面，不再叠旧圆底，缺少专属素材的配置入口沿用uni-icons。
- 鱼类可选图统一使用fish-shrimp，不恢复重复fish文件；国产与进口水果允许选择不同交付原图。去重针对重复素材文件，不合并真实分类或强制不同分类使用同图。退役素材移至仓库根delete，不删除商品分类或商品资料。
- 首页分类横栏只承载商品分类；领券中心与我的优惠券并排位于“我的”顶部、常用功能之前，不在首页固定展示领券横条，也不在常用功能网格重复。未登录点击沿用登录守卫；后台发布组件的正式优惠券链接仍按配置跳转。
- 我的优惠券使用另行交付的折扣券PNG，记入mall-profile来源清单并标记独立交付素材；与领券中心共用mine__coupon-image尺寸，不再使用皇冠图标。
- 首页分类栏以滚动视口的25%作为每项宽度，一屏完整四列，与下方快捷入口居中对齐；其余分类通过横滑可达，不能用slice裁掉正式分类。
- 首页和分类页展示正式启用分类树，空分类入口也保留，不能按商品数量二次过滤。分类页显示时刷新目录；空商品列表显示“暂无商品”，请求错误保留重试，切换分类按请求序号丢弃旧结果。
- 店铺资料状态集中在 `store/modules/mall/storefront.js`；页面通过 `use-mall-storefront` 在显示时刷新。只读取公开名称和链接，不复用后台管理接口。断网保留上次成功资料，清空链接要立即移除复制入口。
- 说明页按 `onShow` 读取已发布正文，序号丢弃过期响应；41405 是未发布空态，网络失败提供重试。不得用草稿替代公开内容。
- 三类品牌渐变集中由 `mallThemeGradients` 派生并通过主题 CSS 变量使用；首页顶部独立读取已发布的headerStartColor/headerEndColor，由mallHeaderGradient提供浅绿白默认与前景色，后台预览采用同一规则。仅首页可见时同步原生导航文字，避免隐藏Tab更新其他页状态栏。修改 FRESH 兜底时同步 JS、SCSS 和全局变量。空首页发布保留默认首页，不能只按 releaseId 判断是否有装修组件。
- 营销装修不替代真实常购/新品/商品目录；主Banner为2.5:1，后续专题图为3:1，图片自带文字不再叠标题。首页一级分类只读正式可见树，不能从素材包伪造入口。
- 空状态优先在公共 `XsyEmpty` 传 kind/imageSrc，保留错误与无数据的区别及重试；不要在各页复制图片/按钮结构。静态小图使用轻量PNG，营销大图走文件服务，不将原素材整包加入主包。
- 登录页按 `DESIGN.md` 的 `mall-login` 模式使用交付拆分图：media/mall-login的hero和waves在线加载，src/static/mall-login的Logo、微信及表单小图留在包内；输入框保留图标与placeholder，不重复显示手机号/密码标签，保留可访问名称。表单使用真实输入和按钮，密码显隐不得清空值。登录按钮只保留文字，不加箭头；店铺名仍从公开配置读取，不把品牌Logo当店铺名配置。
- `media/mall-visual/sources.json` 标记“优化素材”的记录来自后续交付包，其他沿用完整素材包；替换时保留来源哈希与原图字节，不为包体积继续压缩大图。资源清单、MinIO摘要目录和VITE_APP_MEDIA_URL保持一致；发布步骤见README。
- 首页、启动、共享状态与请求逻辑保留包内；大插画统一通过mallMedia生成地址并由XsyRemoteImage保留尺寸及失败兜底。页面恢复后允许重试，核心操作不依赖装饰图成功。不要引入自定义分包重排插件；组件沿用easycom和微信按需注入。
- pages-sub作为普通业务分包根目录，子目录保留既有页面路径；只供分包使用的模块和组件归入pages-sub/shared。使用tools/verify-package.mjs审计编译产物依赖闭包，主包不得含仅分包使用的JS或反向引用分包。
- 登录按钮使用当前主题primary到dark的较浅渐变，保留白字与禁用态；此页面模式不改全局action渐变。
- 登录表单与密码登录按钮常驻，账号帮助提示放在登录按钮与微信图标之间。微信图标由原生getPhoneNumber授权事件提供code；只提交code，不信任客户端手机号。复用服务端profile的会话改密信息，不在前端单独跳过改密守卫；取消授权不发请求，两种方式共享防重状态。
- 微信回调取消、隐私声明或接口能力错误与服务端手机号未开通分开处理；只有有效code才请求后端。登录直接复用按钮loading，不叠加会与页面跳转、toast竞争的全局showLoading/hideLoading。
- 购物车顶部不常驻通用结算说明条，订单列表顶部不放独占行的商品汇总入口；按实重说明沿用确认订单明细里的场景提示，保留失效商品与金额错误等即时反馈。
- 商城先接单后采购：详情步进按服务端起订量、递增量和sellable控制，不能用availableQty卡住缺货预订或限制订购量；库存状态只负责展示，结算/提交由服务端重验。
- 商品卡片操作由product-card统一维护：外层保留至少44px点击区，action-face承载28px高的紧凑按钮外观；不要将触控下限直接用作描边高度，也不在首页、分类或搜索页分别覆盖按钮尺寸。
- 商品卡片不渲染价格来源标签；市场价、时价、协议价等来源统一在商品详情展示，适配器与展示文案映射仍覆盖完整后端枚举。
- 确认订单的商品行使用固定缩略图、独立名称/规格/单价数量与右侧金额，保持与订单明细相同的信息层级；模板新增co-item、co-tip、co-alert节点时同步检查样式，不能让原生image默认尺寸撑满页面。
- 交易页底栏复用styles/mixins.scss的action-bar-spacing，保留12px基础留白并叠加安全区；购物车位于自绘导航上方，不能再次叠加导航承担的安全区。详情和购物车数量控件共用quantity-control，按钮热区至少44px。
- 公共商品卡片的preorder动作只发click进入详情确认，不直接发add；现货仍快捷加购，详情确认复用use-mall-cart。成功提示保持简短。
