# SCM 本地回归

- PostgreSQL 集成用例必须使用独立测试库；非事务用例还应校验数据库用途，不能为了执行而移除隔离门禁。
- 只读投影夹具须满足现行业务约束：线路发车/签收同时推进订单唯一当前状态；锁单标志须与锁定时间和操作人一致。
- 排查权限失败时先补齐被测流程所需的真实授权；仓库范围与订单负责人范围分别校验，不把领域保护移除。
- JDBC 金额与税率参数使用 `BigDecimal`，不能依赖字符串到数值的隐式转换；员工姓名等随机夹具遵守实际字段长度。
- 导出与错误文案跟随当前正式用语，保留文件内容、金额、行定位、事务回滚和权限断言；不得以更新文案为由删除业务约束。
- Excel金额改为可计算数值时，同步更新单元格类型与金额精度断言，不能仅删除原字符串断言；客户模板回归还需覆盖缺成本、未称重和公式缓存。
- 迁移用例只加载当前模块目录；原SQL回放通过LegacyMigrationSql从固定Git提交读取，不复制退役SQL为资源。PgITMigrationHistory识别完整模块安装或保留旧历史的显式切换基线，结构、数据和金额断言仍须保留。
- CHECK白名单门禁读取当前模块SQL，兼容PostgreSQL规范化的ANY/CAST表达式，必须保留枚举覆盖与分支归属断言，不能改为只核对旧Git SQL。
- 菜单回归逐项核对现行路由与Permission Catalog，并验证已撤销权限不再授权；新库无需保留软删历史占位，不能据旧物理行数判断功能缺失。
