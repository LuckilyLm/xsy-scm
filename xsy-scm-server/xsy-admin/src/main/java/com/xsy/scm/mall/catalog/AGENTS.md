# 商城目录

- 每层分类传递iconFileKey及文件服务解析的iconUrl；批量解析公开图标，不接受客户端任意URL，也不将私有图片暴露给客户。

- 分类导航与商品可见性分离：从启用且未删除根节点递归读取启用子树，空分类同样返回；停用或删除的祖先分支不能提升为根节点。
- 分类接口仍要求正式客户身份且已修改临时密码；商品列表、详情继续按客户可见范围及上下架过滤，不能因导航显示空分类而放宽商品权限。
- 首页装修分类链接复用同一导航约定；分类下无可见商品按成功空分页处理，不使用不存在错误。
- PostgreSQL回归入口为 `MallCategoryNavigationPgIT`；测试自行创建完整三级分类，不依赖存量种子分类层级。
