# 商品域

- 分类图标用icon_file_key保存文件中心已上传的public/image图片；后端校验存在性和图片类型，空值清除。树与详情批量/单次解析公开URL，商城目录复用该字段，不能维护另一套名称猜图规则。

- 沿用根目录规则。商品主档、规格、分类、图片等保持现有Service职责；Excel入口为ProductExcelController，导入解析与整批写入分别在ProductImportService和ProductImportWriteService。
- 商品导出默认列与自选列采用同一规模校验：商品查询多取上限一条，并在规格展开后检查实际行数；超过十万行在发送文件前返回公共41112错误，不截断后报告成功。
- 导入更新仍须编辑权，整批校验通过后才在独立事务中写入，任一失败整体回滚；不能为满足导出格式而放松导入定位键、版本与枚举校验。
