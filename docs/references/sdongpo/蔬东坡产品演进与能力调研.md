## 1. 厂商与产品背景

- 品牌：蔬东坡，隶属**北京木屋时代科技有限公司**，成立于 **2014 年**，总部长沙，在北京、广州、武汉、杭州、成都、西安、郑州等设有 **8 大服务中心**。
- 赛道：生鲜食材供应链数字化，提供生鲜配送 SaaS ERP、中央厨房软件、社区团购系统、食材阳光智慧采购平台。
- 市场位置：据百度百科引述，2021、2022 年行业排名第一，市场份额分别 **45.7% / 46.8%**；累计服务客户超万家，SaaS ERP 年交易流水超 1000 亿。
- 品牌主张：**"让生鲜人每天多睡两小时"**；官网称"每 10 家生鲜配送企业，就有 7 家选择蔬东坡"。
- 目标客群：企事业单位食堂配送、餐饮酒店配送、团餐团膳食堂承包、学生营养餐中央厨房、肉类加工与分割、净菜加工。

## 3. 能力全景（按业务模块）

以 17.5 版本为截面，蔬东坡的能力分布如下（条目取自更新日志，代表纵深而非全集）：

### 3.1 订单
- 订单来源：商城、后台录单、AI 录单、订单助手、直采单导入、外部平台（美团）。
- 价格与数量：下单金额 / 发货金额分离；订单助手改市场价联动多单位；实收变更、追加修改、反审核。
- 自定义字段：文本 / 单选 / 数值 / **数值计算**四类，支持多位小数（2–10 位）与三种舍入；订单、订单明细、订单退货、客户对账单多层级。
- 附件（最多 30 个）、订单标签、打印次数、变更记录、异常订单。
- 订单变更采购协同、订单直采。

### 3.2 采购
- 采购单按单据 / 商品双视角；采购进度、计划采购金额 / 已收货金额 / 实际金额。
- 采购协议价：有效期筛选、基于采购协议价的定价公式、最近一次进价权限。
- 询价报价：供应商评分、平均价 / 中位价对比、询价有效时间。
- 供应商分拣：按采购任务实时分配模式、按下单时间查询。
- 厂商信息维护（配合溯源）。

### 3.3 库房 / 库存
- 库区、库位、货架、批次库存、库存上下限、售卖库存下限。
- 入库：按协议单刷价、掌上库房无单收货、其他入库 / 报溢入库。
- 拣货：规则模版机制（按客户 / 按线路 / 仅按存储方式）、批次占用规则、约束规则；掌上库房按商品拣货。
- 库存单位转换继承业务批次号与库区库位；商品转换单。
- 分拣端按基础单位汇总、客户编码 / 临时分拣编码、商品别名导出。
- 缺货标记、重置、拆单；拣货单一键打印小票。

### 3.4 配送
- 线路、司机、车辆、物流排线、配送进度；按订单 / 客户指派线路司机而不影响默认线路。
- 发货单 / 发货检测单模板：完全自定义、批量打印、分组模板按分类拆分打印、单号二维码、生产日期（批次）+ 数量。
- 合并打印规则（相同商品单价相同才合并）、按客户编码 GBK 排序打印。
- 预包装司机扫码分拣装车、司机执法记录、GPS 轨迹导出与车载视频监控。

### 3.5 客户
- 客户档案、客户类型、客户集团、结算主体、账期、授信额度、业务员、客户标签、子账号。
- 定价体系（见 §4）：协议价、客户类型价、客户折扣（计算折前价 / 折后价）、阶梯价、市场价、时价。
- 客户商品可见性（指定客户售卖 / 屏蔽）、商品副别名。
- 客户结算、对账单、对账确认单；退货对账、结算单冲销 / 反结算。
- 拓客 CRM：业务员代客下单、代客支付、代客新增 / 编辑客户、拜访统计。

### 3.6 营销
- 限时抢购、活动专题、优惠活动；活动展示客户类型价并与类型价联动。
- 商城：微信 / 小程序 / PC / 支付宝多端商城；自定义搭建、主题模板（节庆皮肤）、首页弹窗、公告、售后规则。

### 3.7 财务
- 客户结算、对账、结算单、账款、余额、资金流水；反结算 / 冲销、多退少补回客户余额。
- 供应商结算、自助对账结算、供应商客户对账导出。
- 服务费：可配置是否参与结算，参与时按分拣数量重算并生成对账结算单。
- 业财一体：用友 U8 凭证、用友 T+ 多单据同步（客户 / 供应商 / 存货分类 / 部门 / 业务员映射）。
- 报表：销售、采购、毛利、进销存、损耗、营业数据。

### 3.8 溯源 / 食安
- 检测报告（绑定库存批次 / **绑定生产批号**两种模式）、厂商质检资料、高拍仪上传。
- 溯源确认、溯源大屏、商城 / 打印 / 导出展示；到期日期管理、打印次数与分拣状态。
- 地方监管平台对接：福建一品一码、漳州市一品一码、多地溯源平台；食材阳光智慧采购平台（政府 / 校园）。

### 3.9 应用 / 生态与硬件
- 应用中心：订单助手、采购助手、供应商端、配送助手、分拣软件 / 分拣端 Pro、溯源小程序、掌上库房。
- 硬件：智能一体秤、供应商分拣秤、收货秤、标签打印、高拍仪、执法记录仪、**AGV 智能分拣机器人（对接极智嘉 RMS）**。
- 外部对接：美团餐饮智能版、用友、各地溯源平台、Open API、多小程序站点。
- 集团 / 多站点：集团端、总站点、多站点模式。

## 4. 关键机制：价格体系（对 xsy-scm 价值最高）

蔬东坡的价格维度在更新日志中反复出现，已形成多层结构。17.5 版本明确定义了**取价优先级**：

```text
协议价 > 下单默认（上笔订单商品价）> 客户商品折扣（计算折后价）
      > 商品阶梯 > 客户类型价 > 市场价
```

- **计算折前价**（原"客户折扣率"）：客户维度 / 按商品 / 按分类 / 统一折扣，可批量编辑与导入导出。
- **计算折后价**（原"商品折扣"）：在折前价基础上再打折；开启客户类型折扣率时商品折扣不可用。
- 协议价定价公式支持取"采购协议价"作基准价。

> 对本项目的意义：xsy-scm 当前基线是"有效协议价优先、市场价回退"，且明确要求**保持现有优先级不变、新增需独立规格**（见页面级调查 §4）。蔬东坡的完整优先级链可作为**未来价格中心设计的参照目标**，但不能直接覆盖当前已锁定规则。

## 5. 趋势洞察（三条主线）

1. **食安合规驱动溯源成为刚需。** 从 15.4 起，溯源平台对接几乎每个版本都在推进（福建、漳州等多地一品一码），17.5 更用"生产批号"把溯源与库存批次解耦，降低中小客户使用门槛。溯源已从增值功能变为投标 / 合规门槛。

2. **供应商与客户双侧协同持续加深。** 供应商从"被录入"走向"自主管理"：自建商品、分拣、对账、售后、联营、维护厂商信息、小程序操作。客户侧则是商城自助下单、代客下单、自助对账。**系统边界正在从"内部 ERP"扩展到"上下游协同平台"。**

3. **可配置化 + 自动化硬件两条腿走路。** 一边是高度可配置（自定义字段、规则模版、计算折前/折后价、打印模板、商城搭建），用配置覆盖长尾客户差异；一边是硬件自动化（智能秤、AGV 机器人、高拍仪、执法记录仪、GPS），用设备替代人力。二者共同指向"降本增效"这一核心卖点。

补充观察：**移动化 / 掌上作业**贯穿始终（掌上库房、分拣端 Pro、配送助手、拓客 CRM 小程序、供应商小程序），说明生鲜配送的真实作业场景在仓库现场与车上，而非电脑前。

## 7. 风险与边界提醒

- **范围控制：** 蔬东坡是运营 12 年的成熟 SaaS，功能广度远超 xsy-scm 当前阶段。更新日志是"能力全集"，不等于本项目本期任务，不可直接转化为需求清单。
- **不照搬内部实现：** 公开日志与帮助中心只能证明"界面上有 / 官方说支持"，无法反推数据库模型、事务边界、计价公式、抹零规则或权限实现。
- **合规相关：** 溯源涉及各地监管平台（一品一码等）与政府 / 校园采购场景，若本项目涉足需单独确认资质与数据上报合规要求。
- **硬件与生态：** AGV、智能秤、用友对接、美团对接等依赖第三方授权与设备，属于高成本能力，应按实际客户需求单独立项。

## 8. 结论

1. 蔬东坡的产品主线是：**内部 ERP → 上下游协同 → 合规溯源 → 自动化 / 可配置化**，其演进路径对本项目的路线图具有较强参考价值。
2. 本项目 Sprint 5–12 的规划方向与蔬东坡的能力版图高度吻合，说明路线图方向正确；差异主要在于**深度与阶段**，而非方向。
3. 近期最值得对齐的是**价格体系**、**分拣规则模版**、**溯源生产批号模式**三项；中远期关注**供应商协同门户**与**业财对接**。
4. 所有借鉴都应回到本项目已确认的业务规格与技术约束（Java 21 + React、模块化单体、SPU/SKU、无外键、追加式库存流水），**参考布局与流程思想，不覆盖既有实现**。
