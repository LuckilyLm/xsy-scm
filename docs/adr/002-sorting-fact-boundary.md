# ADR-002：分拣事实边界

- 状态：Accepted
- 日期：2026-09-24
- 原始决策记录：[2026-09-28 决策归档](../archive/decisions/decisions-2026-09-28.md)

## 背景

发货量来自仓库实际分拣结果。分拣记录需要与订单需求和后续配送资格保持可追溯关系。

## 决策

- 分拣只产出 `sorting_task_item.sorted_quantity`，不回写订单实际数量或结算字段，不改库存余额或流水，也不创建出库单。
- 每个有效订单行同一时刻最多被一个活动分拣任务占用；取消任务时同事务释放其所有活动明细。
- 完成任务要求每条有效明细已有结果。已完成任务只能通过带原因和版本校验的重新打开命令恢复工作；数量与原因记录保留。
- 配送候选资格要求订单已确认且有效明细都被已完成任务覆盖。
- 分拣数据范围为授权仓库与当前分拣员的交集。跨分拣员查看由明确的任务分配权限控制。
- 打印只登记次数、时间和操作人，不改变任务状态或版本；称重由人工录入。

## 结果

配送使用已完成分拣任务作为发货数量来源。重新打开的订单会退出配送候选池，历史线路分配不会被自动释放。
