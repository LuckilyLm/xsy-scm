# ADR-004：Finance R1 财务事实

- 状态：Accepted
- 日期：2026-09-26
- 原始决策记录：[2026-09-28 决策归档](../archive/decisions/decisions-2026-09-28.md)
- 详细设计：[Finance R1 设计](../plan/active/finance-r1-design.md)

## 背景

财务需要消费已经确认的采购、配送和退货事实，并记录应收、应付、收款和付款；它不能反向成为订单、库存或采购状态的第二个权威来源。

## 决策

- Finance 通过只读 DAO 消费订单、采购、库存、配送和退款事实，不写这些业务表。
- 财务记录是追加事实：更正使用反向记录，不更新或软删除原记录。财务表不存储可由事实推导的结清、余额或核销状态。
- `NORMAL`、`RED` 或 `REVERSE` 类型表达方向，金额本身保持正数。应收、应付红字与收付款反向记录使用各自的类型约束。
- 自动应收、应付生成与触发订单、收货或退货动作处于同一事务。退货生成红字不设原应收余额上限，不能阻断已批准的业务退货。
- 收款遵循客户销售归属范围；客户退款付款必须与已完成的退款事实逐值一致。登记不自动核销，也不二次冲减应收。
- 冲正只允许在未被核销使用时追加；业务来源唯一约束与请求幂等分别负责各自的重复保护。

## 结果

当前功能只产生并记录财务事实。核销、查询导出、反向登记和后续财务阶段按活动设计逐步交付。
