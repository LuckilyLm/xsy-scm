# ADR-003：配送出库与签收

- 状态：Accepted
- 日期：2026-09-25
- 原始决策记录：[2026-09-28 决策归档](../archive/decisions/decisions-2026-09-28.md)

## 背景

发车需要把分拣结果转换成唯一的库存出库事实，同时保证线路、订单、预留和库存在并发情况下保持一致。

## 决策

- 发车是订单销售出库事实的唯一生产入口，数量取 `sorting_task_item.sorted_quantity`，不重新读取订单申报数量。
- 一条线路的发车整体原子化；任何订单失去资格都会拒绝整条线路。每条线路生成一张已确认出库单，出库明细保留订单行来源。
- 库存写入委托给库存域命令。预留在同一事务中整条消费或释放，再扣减发货仓可用量。
- 签收按订单记录 `SIGNED` 或带原因的终态 `EXCEPTION`。签收不会撤销销售出库；退货必须追加独立反向事实。
- 发车使用幂等键和线路版本；签收使用线路订单行版本。司机签收必须检查司机归属范围。
- 打印不触发发车。GPS、自动排线、司机应用、部分签收和自动退款不属于当前交付边界。

## 结果

库存出库与线路发车共同提交，数量来源可追溯到分拣明细；签收与库存冲销保持独立。
