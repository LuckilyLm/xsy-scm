# ADR-008：配送路线示意、辅助排线与分拣设备

- 状态：Accepted
- 日期：2026-10-02
- 修订：2026-10-03，按负责人最新要求收窄配送范围；本修订替代原 GPS 采集、查询及回放建设要求。
- 覆盖：ADM-09～ADM-11

## 背景

负责人明确：配送只需要在地图上显示大概的配送路线，不需要实时 GPS 定位显示。地图 M2、路线示意、辅助排线和电子秤沿用现有服务或设备适配。它们只能增强现有分拣与配送链，不能改变 ADR-002 的分拣事实边界、ADR-003 的发车出库与订单级签收规则。

## 决策

- 地图正式 provider 继续使用高德适配器。客户、仓库、供应商和停靠点坐标必须成对保存并携带 CRS；配置缺失或调用失败时允许成组手工录入经纬度，不允许保存半组坐标。
- 地图、坐标选择和供应商位置查询遵守业务对象现有数据范围。地图展示不代表实时轨迹，也不能直接改变库存、线路或订单状态。
- 配送地图以仓库坐标为起点，按已保存的停靠顺序展示客户点位、编号及带方向的连线，作为计划路线示意。当前用点间连线即可满足范围，不要求真实道路路线、实时车辆位置、轨迹采集/回放、实时交通或 ETA。
- 点位缺失时保留停靠清单和缺失提示，在缺失处断线；不能跨过未定位停靠点拼出貌似完整的路线。地图加载失败仍能看地址、顺序与线路业务详情。
- 现有辅助排线保留为可选工具，不是地图展示的前置条件；不新增复杂优化目标或强制外部路网服务。排线先生成可解释建议，冻结输入停靠点、约束、provider 版本和距离结果；操作者比较后显式确认应用。建议不得自动发车或覆盖已确认线路。
- 距离矩阵通过可替换 provider 契约提供。离线或测试实现必须明确标识为估算/fake，不得宣称为真实路网、实时交通或生产优化结果。
- 已有 GPS 代码属于前一范围的实现，尚未按新要求退场：下一开发阶段移除轨迹页与前端请求，停止对外提供 GPS 上报/查询入口，并通过新增 migration 停用对应权限入口与授权。保留 V88 原文件及历史数据，不回改迁移、不删除轨迹表或清空记录。地图所需坐标、CRS 与 WGS84 转换继续保留。
- 地图和保留的排线建议入口均需源线路功能权限及当前数据范围；排线的生成、历史、应用、放弃不能只检查功能权限。应用时同时核对线路版本、停靠集合与建议冻结输入，防止应用过期建议。
- 电子秤使用“设备事件 → 稳定读数 → 人工接受”链路。设备、原始读数、稳定判定、任务明细、接受人和时间可追溯；重复事件不得重复写入分拣结果。
- 一键分拣只处理已有标准品和可确定任务明细，仍只写已分拣数量。替代商品、非标准品自动结算和供应商代分拣不由一键操作推断。
- 送货时间取任务创建时冻结的快照。线路筛选由预配送波次表达；供应商筛选使用任务上显式冻结的供应商来源，不从 SKU 与供应商多对多关系猜测。
- 发车仍是销售出库唯一入口并整体原子化，分拣不改订单和库存，签收不撤销出库；库存变化只能经过库存域命令。

## 明确排除

- 不纳入部分签收、自动退款、自动结算、替代商品、容差放行、供应商代分拣或无人确认的全自动排线。
- 本期不建设或接入实时 GPS 定位、位置定时上报、轨迹查询/回放；员工端不为配送申请后台定位或持续采集权限。不把模拟秤当真实硬件验收，不从客户端坐标或设备数据扩大授权范围。
- 不承诺离线地图、实时交通、导航 SLA 或历史轨迹长期保存期限；这些能力需要独立决策。

## 外部验收边界

待用户授权验证后，可使用确定性距离矩阵与模拟秤验证 provider 契约、幂等、权限与失败降级。地图验收聚焦点位、停靠顺序、连线方向、缺失点断线及降级；高德授权、密钥/安全代理、配额和目标网络仍需现场核实。GPS 终端与真实路网不再作为本期验收前置；实体电子秤协议、稳定性和校准单独验收。代码可配置不等于生产可用。

## 结果

ADM-09～ADM-11 在保持既有分拣、发车、出库和签收不变量的前提下，以可替换 provider、人工确认和可追溯设备事件增加地图与现场作业能力。
