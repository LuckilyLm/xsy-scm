# 商城主题与标品分拣操作说明

当前可用状态与验收证据见 [项目状态](../status.md)，正式边界见 [业务决策](../decisions.md)。

## 设置商城主题

1. 在管理后台商城首页装修中选择生鲜绿、暖橙或海蓝主题，保存草稿并预览。
2. 确认后发布。微信小程序在打开、恢复前台或切换页面时读取已发布主题；仅保存草稿不会改变用户端页面。
3. 需要恢复时，从发布历史回滚目标版本。回滚同时恢复该版本的装修内容和主题。

主题读取失败时商城显示默认生鲜绿，可以重新进入页面重试。成功、警告、错误、收支与账单状态的颜色不随主题切换。

## 确认所选标准品

1. 当前受指派人打开分拣任务详情；如有手工录入草稿，先提交手工录入。
2. 点击“标品一键分拣”，核对预览中的订单、客户、商品、规格、确认数量和单位。
3. 勾选本次实际已准备好的可确认明细，点击“确认所选标品”。不同单位的数量不合计。
4. 确认成功后回到任务详情核对结果。其他明细仍按原流程处理，全部处理后再单独点击“完成任务”。

不可选择的行会显示原因。非标品、已确认行及分次累计量与计划量不一致的行请使用原人工录入流程；包装码问题先核对绑定关系。不要为使用快捷入口而删除历史分次记录。

网络结果不明时，可以重试原操作；系统会防止重复确认。出现版本、状态或权限变化时，先刷新预览，再核对并重新选择。一个批次中有行不符合条件时，整个批次都不会确认。
