## 持续约束

- `xsy-scm-customer-app/` 是正式客户商城；冻结的 `xsy-scm-miniapp/` 不继续二开。商城订单、库存、资金与售后复用正式领域事实，不建第二套账或状态机。
- 服务端决定可见商品、客户价、促销、数量规则和最终金额；客户端显示结果与阻断原因，不自行估算缺失事实。共享结算资金可见性和可用性按正式客户与结算主体规则处理。
- 商城幂等指纹只包含稳定业务字段。可变地址内容、价格快照和版本号不放进重试指纹；同键成功重放应先读取首次结果，再做会随时间变化的前置校验。客户可见操作记录使用白名单，不展示内部审批原因。
- 新迁移只追加版本；测试、构建、迁移演练和现场验收分别记录实际结果。每批完成时更新[项目状态](../../status.md)与本表中仍未完成的工作，历史过程由 Git 追溯。
