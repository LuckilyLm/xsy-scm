# 商城资金只读契约

商城资金接口只从商城会话取当前业务客户，不接受客户端指定客户、结算主体或钱包账户。`/scm/mall/funds/**` 由商城客户拦截器鉴权，并要求首次登录的临时密码已经修改。员工余额和 Finance 接口不向商城开放。

钱包余额属于结算主体，不能拆成某一个子客户的“个人余额”。当前安全默认是：普通独立结算客户可见真实钱包总余额；集团结算子客户及集团主体采购账号不展示共享总余额或授信总额度。流水只按当前业务客户的 `customer_id` 与合法结算主体双重过滤，账户、其他成员流水及内部更正原因不下发。集团是否允许受权账号查看汇总，仍需单独的产品与权限决策。

账单列表和详情只读取 `xsy_finance_receivable` 中当前业务客户及其原销售订单均归属当前客户的正常应收。红字和有效核销后的净额直接复用 Finance 的 `receivableSummarySelect` SQL 片段；详情不存在与越权使用同一个“账单不存在”结果。授信概览只汇总当前客户的应收与已确认未转应收订单，集团总敞口不下发。`creditLimit=0` 不显示成无限额度或负可用额度。到期日由数据库按已冻结的账期规则生成，客户侧只展示正式 `due_date` 事实。

金额沿用服务端四位定点字符串。客户可见流水只包含单号、类型、方向、金额、发生时间，以及确认属于当前客户的订单号、退款单号或充值单号；不包含资金来源主键、操作员、内部审批原因或后台日志。列表在 SQL 中完成归属过滤和分页。

本契约只读，不创建第二套钱包或应收账本，不提供充值、还款与支付方式选择命令。
