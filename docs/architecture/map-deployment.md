# 地图接入的部署与使用

适用对象：负责部署鲜蔬源管理后台的运维与实施人员。本文只写**当前代码实际支持的配置与行为**；未实现的能力（离线地图、实时交通、导航 SLA、轨迹保存期）见文末「不承诺的能力」。

规则来源：[ADR-008](../adr/008-map-routing-gps-and-sorting-devices.md)、[有效决策](../decisions.md)。

## 1. 当前接入范围

| 业务对象 | 点位字段 | 维护入口 |
| --- | --- | --- |
| 客户 | `longitude` / `latitude` / `geomCrs` | 客户表单「地图定位」 |
| 仓库 | 同上 | 仓库表单「地图定位」 |
| 供应商 | 同上 | 供应商表单「地图定位」 |
| 配送停靠点 | 同上（另有 `addressSnapshot`） | 线路详情内的停靠点编辑 |
| 订单收货地址 | 下单时从客户快照而来 | 不单独维护 |

展示侧：管理后台的供应链地图大屏按**已授权范围**渲染上述点位。地图只做展示与选点，不改变库存、线路或订单状态。

## 2. 坐标系（CRS）约定

- 每个点位**必须**同时带 `longitude` / `latitude` / `geomCrs` 三列，数据库约束 `ck_*_location_complete` 会拒绝半组坐标，表单也做同一条校验。
- 允许的取值只有两种：`GCJ02`（高德 / 腾讯底图）与 `WGS84`（天地图 / OSM / 绝大多数 GPS 设备）。
- 高德 JSAPI 返回的是 `GCJ02`；若点位的 CRS 与当前底图不一致，选点组件会通过 JSAPI 的坐标转换接口换算后再保存。**不要手工把 WGS84 的经纬度标成 GCJ02**：偏差在几百米量级，且不会报错。
- 没有 CRS 的经纬度在换底图时会静默偏移，因此「先存坐标、以后再补 CRS」这条路是走不通的。

## 3. 环境变量

Web 端（`xsy-scm-web`）从 Vite 环境变量读取配置，模板见 `xsy-scm-web/delivery.env.example`。复制到对应 mode 的本地环境文件（例如 `.env.localhost.local`），不要提交含密钥的文件。

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `VITE_AMAP_KEY` | 是 | 高德 **Web 端（JSAPI）** 应用的 Key。未配置时地图不可用，但点位仍可手工录入。 |
| `VITE_AMAP_SERVICE_HOST` | 生产建议 | 代理地址，以 `/_AMapService` 结尾。安全码留在代理服务器上，浏览器只拿到代理地址。 |
| `VITE_AMAP_SECURITY_CODE` | 仅开发 | 没有代理时的临时方案。`VITE_*` 是**构建期公开变量**，打进产物里任何人都能读到，因此生产环境不要用这一项。 |

`VITE_AMAP_SERVICE_HOST` 与 `VITE_AMAP_SECURITY_CODE` 同时存在时优先使用前者。

## 4. 高德控制台侧需要做的事

1. 创建 **Web 端（JSAPI）** 类型的 Key，不是 Web 服务或 iOS/Android 的 Key —— 三者不通用。
2. 配置 **域名白名单**：填实际访问管理后台的域名（含端口按高德要求）。白名单不含当前域名时表现为地图加载失败或大量请求被拒。
3. 确认 Key 已绑定所需的 JSAPI 版本（代码使用 `v=2.0`）与插件 `AMap.Geocoder`（地址解析）。插件缺失时「按地址定位」不可用，但选点与手工录入仍可用。
4. 核实配额与商用授权：配额、计费方式与商用条款以高德控制台当次的实际条款为准，**不要沿用历史调研里的版本、费用或结论**。
5. 如果部署在高德要求安全密钥的形态下，按第 3 节配置代理，并把安全码放在代理服务器，不要放进前端产物。

## 5. 无外网 / 未配置时的行为

代码把「地图不可用」当成**可降级**而不是致命错误：

- 未配置 `VITE_AMAP_KEY`：选点组件不加载 SDK，界面提示「地图尚未配置，可先手工填写经纬度」，经纬度与 CRS 仍可手工录入并保存。
- SDK 加载超时（15 秒）或网络失败：提示「地图加载失败，请检查网络或地图配置后重试」，已录入的坐标不会被清空。
- 地图服务请求超时（12 秒，例如地址解析）：提示超时并允许重试。

因此**离线部署是可行的**，代价是选点、地址解析和地图大屏不可用，点位靠人工录入（需要具备经纬度来源，例如手机定位或现场测量）。

## 6. 部署环境验收清单

代码可配置 ≠ 生产已配置。上线时按下面逐项确认并留记录：

- [ ] 访问域名与高德 Key 白名单一致；浏览器控制台无 Key/白名单相关报错。
- [ ] 在客户、仓库、供应商、停靠点四处各选一个点，保存后重新打开，坐标与 CRS 与保存时一致（未被底图换算污染）。
- [ ] 断网或临时移除 Key，确认界面给出降级提示且不影响其它功能与既有数据。
- [ ] 地图大屏只显示当前账号被授权的仓库与客户范围（换一个范围更小的账号复核）。
- [ ] 确认配额与商用授权状态，并记录当前条款的核对日期。
- [ ] 若使用代理：确认代理可用、安全码未出现在前端产物中（可在构建产物里搜索一次）。

## 7. 不承诺的能力

以下能力当前**没有**实现，也不由本文承诺；需要时另行决策：

- 离线地图与离线底图缓存。
- 实时路况、导航与到达时间预估（SLA）。
- 把地图点位当 GPS 使用。地图上的点是「登记位置」，不是实时轨迹；轨迹能力见 ADR-008 的后续工作包。
- 历史轨迹的长期保存期限。
- 从客户端坐标或设备数据扩大授权范围：地图展示遵守业务对象既有的数据范围，不因为「地图上看得见」而获得额外访问权。
