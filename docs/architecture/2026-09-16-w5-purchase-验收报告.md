## 6. 冻结与边界

- **V1–V12**：与 PostgreSQL Closure 清单 **12/12 逐字节一致**，未修改。
- **V13/V14**：与 W4 清单 **2/2 一致**，未修改。
- **V15/V16**：已由 Flyway 应用，冻结于 [w5-applied-migrations.sha256](./w5-applied-migrations.sha256)。
  后续只追加新 migration。
- Product / Customer / Supplier / Pricing / Order / `sa-base` / 系统域 / C 上游参考 / 小程序：
  源码零修改（`verify_w5_legacy.py` 断言 D 覆盖）。
- **零库存实现**：全仓无 `inventory_balance` / `inventory_movement` 等库存表，无库存写入，
  `PurchaseInventoryContract` 零调用点（断言 E）。
