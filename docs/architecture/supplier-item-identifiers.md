# 供应商货号与内部 SKU 的关系

适用模块：供应商关联商品（xsy_supplier_sku）。核对日期：2026-10-18。

## 标识与录入归属

- 内部 SKU 由 XSY 后端发号，供应商货号不能覆盖 SKU 身份。
- 供应商货号由供应商提供、采购人员按原始资料录入；允许空值、最多 100 字符。只去掉前后空格，保留大小写和前导零，不拼日期、产地、价格或批次。
- 外部供应商批号在实际到货/生产批次阶段登记；不存入长期有效的供应商货号字段。
- 系统内部追溯批次和逐包装码需要独立建模；本模块未实现一物一码。

## 本地改动边界

数据库迁移 V149 为既有供应商-SKU 关联增加 nullable 的 supplier_item_code，并对同一供应商活动关联建立非空货号唯一索引。原有数据不回填假货号；空货号可以存在多条。不同供应商允许使用相同货号；大小写不自动折叠。

供应商关联商品整表替换继续使用现有供应商行锁、关联行版本、默认来源和软删除机制。新增的货号仅是业务输入字段，支持置空；新建或编辑内部 SKU 身份由原有服务控制。

前端关联商品编辑表格提供供应商货号录入，供应商-SKU 反查列表展示；不添加自动生成提示或给用户编造供应商货号。

## 验收

1. 供应商货号 0007 不等于 7；Ab-01 不等于 ab-01。
2. 同一供应商同一非空货号不能对应两个活动 SKU；空货号允许多个。
3. 改变货号不重编内部 SKU、不删除历史关联主键、不修改已出具的订单/收货单号。
4. 新增数据必须完成 Flyway V149、PostgreSQL 实库唯一约束与后端集成测试后才能部署。
5. 源头证明、供应商货号变更历史、批次与包装实物事件另在追溯模块落地，不假装本模块已有这些能力。
