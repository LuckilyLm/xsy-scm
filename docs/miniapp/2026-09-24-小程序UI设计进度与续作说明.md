## 24.1 已完成代码实现

### ProductCard V1 — COMPLETE（代码）

文件：`xsy-scm-miniapp/src/components/business/product-card.vue`

按 Figma `ProductCard / V1` 重排了信息层级，核心修复是旧版的价格行挤压问题：

旧版把「价格 + 单位 + 价格类型 + 库存」塞进同一横排，实测行宽仅 **123.6px**，
`/份` 被压成两行并与库存行重叠。新版：

```text
商品名称（最多两行）
规格 / 分类
价格类型标签（独立成行）
主价格 + 单位（nowrap，不换行）
库存状态
加购 / 缺货 / 询价
```

- 价格类型标签**独立成行**，不再与价格、单位、库存争抢横向空间
