- 余额充值在验签后的渠道成功时登记收款并给创建时冻结的钱包入账；混合资金退款按各来源剩余可退本金比例分摊。待分配商城订单由有指派权限的员工领取或指派，普通业务员范围不因此放宽。

### 后端字段缺口

以下项目仅记录当前确实缺少的后端只读事实。前端不得从当前分页求和、相近字段或常量拼造结果；补齐时先确认领域事实已存在，再由服务端投影并独立接入页面。

| ID | 场景 | 当前缺口 | 补齐边界 |
| --- | --- | --- | --- |
| B1 | 收货 / 入库报表 | `ReceiptReportVO` 三类明细缺少页面级全量汇总 | 复用列表筛选与仓库范围；沿用各自时间轴；数量按单位分组，成本保留权限及缺失语义 |
| B4 | 销售订单详情 | 库存预留 / 配送状态只读聚合 | 组合库存与配送正式事实，不在订单表双写状态 |
| B5 | 销售订单详情 | 订单退货 / 退款聚合 | 组合退货单与已完成退款事实，不由前端拼第二套状态 |
| B7 | 优惠券列表 | 发放量 / 已领取 / 已使用统计 | 基于券模板与实例只读聚合；若加时间窗口先确定统计口径 |

已具备且不是缺口：Finance 操作流水提供 `operator` / `createdAt`；收货确认人、收货模式、上架状态、优惠赠品详情及成本缺失/权限区分均由正式字段提供。金额或成本未知时不得用 0 代替。已关闭的旧 UI 口径项：共享数字样式已收口，`.num` 已关闭，不再是后端缺口或待决设计。
