## 最近变更与待回归范围

### 工程命名统一

- 后端包根统一为 `com.xsy.scm`，模块为 `xsy-admin` 与 `xsy-base`；前端组件、工具和资源引用同步使用 XSY 名称。
- 升级包含旧缓存类型、浏览器本地配置键与系统任务类名的迁移。源码回归与本地构建的结果由验证记录保存，目标环境部署和真实设备验收仍需单独执行。

### 核心链路六项修复

当前代码包含以下修复：

1. 订单明细替换商品规格按删除旧行、新增新行处理，不继承旧规格的锁定报价和实称量。
2. 未称重的已确认非标行仍按订购量暂计，避免修改订单后结算量丢失。
3. 后台表单提交商品行备注，支持修改及显式清空。
4. 分拣首次录入或分次追加仅推进状态与开始时间，不递增设备共享任务版本；改派、完成、取消和重开仍推进版本。
5. 采购补价重复请求返回原结果先复核当前归属，已成功命令不因后续采购核对或状态变化而被误报失败。
6. 财务过账修改/作废的同编号重复请求返回原结果先返回已成立结果，再处理新请求的旧版本或已作废状态；当前授权仍须校验。

对应回归入口见文末；执行结果以验证记录为准。

### 管理后台统一

- 导出按钮使用主题色实底文字按钮，规范组内/组间间距。
- 表格以文件管理为参照，覆盖 SCM、系统管理与支撑工具；普通只读完整数组使用共享 `LocalTable`，服务端分页继续走正式接口，商品图片中心改为服务端分页。
- 只有一个新增/导出操作时，与筛选同排靠右；无筛选时独占一行靠右。树、编辑/批量确认和打印保留工作流上下文。
- 公共列宽、数字展示、未保存保护及抽屉样式已收敛。表头拖拽调宽已移除，列设置中的宽度配置保留。
- 客户状态与业务员在新增/编辑表单维护，可售商品可在详情页直接调整；供应商采购单位改用计量单位字典，参考价保留四位定点数。

界面规则统一见根目录 [DESIGN.md](../DESIGN.md)。查询、翻页与状态变化的回归通过对应页面用例维护。

## 尚未关闭的业务边界

- 客户月利润的“开票金额”暂按对账金额显示，尚无销售发票台账；税费/服务费等是报表派生，不写回账本。当前客户集合只含当月有应收或月费用者，只有收款或过账者暂不单独成行。
- 秤端源码已有 `/measurements` 和 `/items/{taskItemId}/complete` 派发。`WAITING_CONTRACT` 是本地初始排队状态，不能据此判定同步代码缺失；手工来源 `entrySource/entryNote` 的平台持久化与稳定语义仍须核对。
- 本地 eventKey 凭条与平台正式包装码是两类身份。正式标签必须取平台发码结果；已有包装码绑定不能证明该包装已正式离场。
- L1/L2 保留，逐包装码正式出库/退回、混批拆包谱系和复杂召回不作为已交付闭环，也不自动扩展。
- 短信登录、基于微信身份绑定的静默登录、语音下单、订阅消息、员工移动端、多企业账号授权和订单助手扩展不作为当前已交付能力。微信手机号授权入口已有源码，真实授权与发布仍须单独验收；真实支付渠道仍需另行确认与验收，当前小程序仅下单。
- 地图的真实许可、配额、代理与坐标现场核对独立验收；路线图不提供实时 GPS。
