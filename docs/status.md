- 正式 V2 位于 `xsy-scm-server/`、`xsy-scm-web/`、`xsy-scm-customer-app/`；`xsy-scm-miniapp/` 是冻结的旧目录。后台主干覆盖客户、商品、销售、采购、库存、分拣、配送、财务、报表和运营。客户商城已有认证、目录、购物车、地址、结算下单、订单中心、配送进度、售后、钱包、账期和营销页面。
- 商城订单写入正式销售订单。V129/V130 保存结算方式并以客户开关控制货到付款；PAY-01 支持客户在订单确认后主动余额支付。PAY-02 将账期预览、确认和已确认未开应收订单的占用金额改用净额。PAY-03 登记实际 COD 收款并自动核销。后台支付限制所选结算方式与待付上限、同键余额支付重放、COD 分笔补收及冻结结算主体，已在 2026-10-16 PAY-VERIFY 的隔离 PostgreSQL 定向集成测试中覆盖；财务收款页和后台订单详情已有 COD 操作入口，客户“已付”也计入人工收款对该订单的有效核销。签收后的应付改取实际出库形成的正常应收净额，客户可见已付超出当前应付的差额。
- 余额充值在验签后的渠道成功时登记收款并给创建时冻结的钱包入账；混合资金退款按各来源剩余可退本金比例分摊。待分配商城订单由有指派权限的员工领取或指派，普通业务员范围不因此放宽。
