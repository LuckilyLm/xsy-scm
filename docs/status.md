## 当前代码

- 正式 V2 位于 `xsy-scm-server/`、`xsy-scm-web/`、`xsy-scm-customer-app/`；`xsy-scm-miniapp/` 是冻结的旧目录。后台主干覆盖客户、商品、销售、采购、库存、分拣、配送、财务、报表和运营。客户商城已有认证、目录、购物车、地址、结算下单、订单中心、配送进度、售后、钱包、账期和营销页面。
- 商城订单写入正式销售订单。V129/V130 保存结算方式并以客户开关控制货到付款；PAY-01 支持客户在订单确认后主动余额支付。PAY-02 将账期预览、确认和已确认未开应收订单的占用金额改用净额。PAY-03 登记实际 COD 收款并自动核销。当前未验证源码进一步限制后台支付遵守已选结算方式和待付上限、同键余额支付成功回放、COD 分笔补收及冻结结算主体；财务收款页和后台订单详情已有 COD 操作入口，客户“已付”也计入人工收款对该订单的有效核销。签收后的应付改取实际出库形成的正常应收净额，客户可见已付超出当前应付的差额。
- 余额充值在验签后的渠道成功时登记收款并给创建时冻结的钱包入账；混合资金退款按各来源剩余可退本金比例分摊。待分配商城订单由有指派权限的员工领取或指派，普通业务员范围不因此放宽。
- 当前 Flyway 源码最大版本为 **V134**。V132 新增 COD 分笔收款订单归属列，V131 旧收款行不改写；V133 将客户商品可见性菜单名称改为「商品可见性」；V134 新增商品规格的商城起订量与递增量。V132–V134 尚未执行迁移演练。
- 收货、入库和待入库三张报表已有独立全量汇总接口与页面展示，数量按单位分组，入库成本区分缺失和权限；优惠券列表已有后台发放、商城领取、已使用累计张数及已知冻结券让利。以上源码本轮未运行测试、构建或数据库查询。
- 订单独立详情页已有订单、商品、优惠、库存预留、分拣、配送、资金和售后分区。B4/B5 由只读 DAO 读取正式事实；先校验订单负责人范围，再按仓库、分拣指派人、司机范围与领域查询权限决定可见部分。退款单完成与原资金来源返还分别显示；新旧资金来源都没有可确认事实时不显示为已返还。本轮未运行编译、接口或页面验证。
- 云文件新上传的公开图片改为内联展示，移除错误的 UTF-8 内容编码并补 WebP 类型；pre/prod 云存储配置要求 HTTPS 公开地址与签名 endpoint。旧对象元数据、公网访问、反向代理与混合内容仍需目标环境验收。
- RPT-05 静态核对：首页与报表的销售指标均使用 `CONFIRMED`、`confirmed_at` 和 `settlement_total_amount`；采购指标均使用已提交状态、`submitted_at` 和 `total_amount`。页面权限与数据范围策略仍按既有决策分别执行；未运行对账查询。
- MALL-03 地址页已接入高德地点搜索、GCJ-02 选点和服务端逆地理编码；新增/编辑地址需有省市区及坐标，保存前由后端重验并写入 GCJ-02。微信小程序原生地图底图供应商不由这段源码保证，仍需按高德统一服务要求核对目标平台能力及真机行为。
